# 內容庫

此目錄收錄《武與俠》可直接投入遊戲的擴充資料。所有條目使用核心規則的判定、功力、武勢、輕功、氣血、AC、異常狀態與名望規則。

內容庫按類型拆分為：

- 拿手：`拿手.md` — Skill 的完整可選列表、常用能力與用途
- 絕活：`絕活.md` — Feat 的完整可選列表與機械效果
- 武學：
  - `武學/內功.md` — 15 套完整內功
  - `武學/外功_拳掌長兵.md` — 11 套完整拳掌／長兵外功
  - `武學/外功_劍法.md` — 10 套完整劍法
  - `武學/外功_刀法.md` — 11 套完整刀法
  - `武學/外功_暗器.md` — 6 套完整暗器武學
  - `武學/輕功.md` — 10 套完整輕功
- 毒藥與藥物：
  - `藥物/毒藥.md`
  - `藥物/解毒與療傷.md`
  - `藥物/丹藥與秘藥.md`
- 裝備與物品：`裝備與物品.md`
- 敵人圖鑑：`敵人圖鑑.md`

以上武學條目數與《武與俠》完整系統規則 v1.0 的內容庫一致。具體條目文字優先於一般內容庫說明；若與核心規則衝突，依裁定優先順序處理。新增內容優先放進對應類別，核心規則只保留系統機制。
