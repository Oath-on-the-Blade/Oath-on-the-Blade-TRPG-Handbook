# 內容庫

此目錄收錄《武與俠》可直接投入遊戲的擴充資料。所有條目使用核心規則的判定、功力、武勢、輕功、氣血、AC、異常狀態與名望規則。

內容庫規劃按類型拆分為：
- 拿手：Skill 的完整可選列表、常用能力與用途
- 絕活：Feat 的完整可選列表、前置條件、效果與重複取得規則
- 武學：內功、拳掌／長兵、劍法、刀法、暗器、輕功
- 毒藥與藥物：毒藥、解毒與療傷、丹藥與秘藥
- 裝備與物品：武器、護具、暗器與機關、江湖物資
- 敵人圖鑑：凡俗與幫派、門派武者、異獸與奇物、首領與宗師模板

具體條目文字優先於一般內容庫說明；若與核心規則衝突，依裁定優先順序處理。新增內容優先放進對應類別，核心規則只保留系統機制。
