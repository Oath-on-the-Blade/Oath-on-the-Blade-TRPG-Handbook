# 內容庫

此目錄收錄《武與俠》可直接投入遊戲的擴充資料。所有條目使用核心規則的判定、功力、武勢、輕功、氣血、AC、異常狀態與社會名譽規則。

昊國世界、十六門派沿革、固定人物與地理不在本目錄重複定義，見 `lore/README.md`。Lore 中提及某武學或人物，只提供世界背景；機械效果與正式可選條目仍以本內容庫為準。

內容庫按類型拆分為：

- 拿手：`拿手.md` — Skill 的完整可選列表、常用能力與用途
- 絕活：`絕活.md` — Feat 的完整可選列表與機械效果
- 相對名譽對象：`相對名譽對象.md` — 可跨劇本保存的統一社會大類、正式具名勢力及其 `c` 值登錄表；劇本不得自行新增數值對象
- 武學：
  - `武學/內功.md` — 18 套完整內功（含 3 套無門派）
  - `武學/外功_拳掌.md` — 11 套完整拳掌外功（含 1 套無門派）
  - `武學/外功_長兵.md` — 10 套完整長兵外功（含 1 套無門派）
  - `武學/外功_鞭法.md` — 7 套完整鞭法（含 1 套無門派）
  - `武學/外功_劍法.md` — 11 套完整劍法（含 1 套無門派）
  - `武學/外功_刀法.md` — 12 套完整刀法（含 1 套無門派）
  - `武學/外功_暗器.md` — 7 套完整暗器武學（含 1 套無門派）
  - `武學/輕功.md` — 13 套完整輕功（含 3 套無門派）
- 毒藥與藥物：
  - `藥物/毒藥.md`
  - `藥物/解毒與療傷.md`
  - `藥物/丹藥與秘藥.md`
- 裝備與物品：`裝備與物品.md`
- 敵人圖鑑：`敵人圖鑑.md`

既有武學條目以《武與俠》完整系統規則 v1.0 為基礎，另按本版規則擴充長兵、鞭法與無門派散修武學。具體條目文字優先於一般內容庫說明；若與核心規則衝突，依裁定優先順序處理。新增內容優先放進對應類別，核心規則只保留系統機制。

條目標示「無門派」只表示它不屬任何門派正式傳承，不代表自動公開或免費可學。角色仍須依 `遊玩規則/10_升級探索與NPC.md` 記錄師承、秘笈或人脈來源及傳承上限。

`相對名譽對象.md` 具有**登錄表權威**：劇本可以引用已存在的統一大類或具名勢力，但不能在劇本檔內另創永久相對名譽數值。若新劇本確實需要新的持久對象，先修訂內容庫登錄表並決定其範圍與 `c`；若現有分類足以涵蓋，使用既有大類；若分類過粗，先在 Handbook 層級拆分，不由單一劇本私設。

## Markdown 格式規範

內容庫採用一致的 Markdown 結構，方便人類查閱與 AI 精確解析：

1. 每個檔案只使用一個 `#` 一級標題，不重複同名標題，也不以粗體標記包住標題文字。
2. 同一類內容若拆成多個檔案，兄弟檔必須使用相同的條目層級、欄位順序與分隔符。
3. 每個獨立可選條目原則上使用 `##` 標題；若檔案本身另有大類分區，分區使用 `##`、條目使用 `###`。
4. 武學條目頭依該類別使用固定欄位順序。外功統一為：`【名稱】門派｜正式風格或外功類別｜武器（如適用）｜主屬性｜武勢`。所有外功資源一律稱為「武勢」，不另設劍意、刀勢、掌勁等資源別名。
5. 若 `遊玩規則/07_外功.md` 已為該類外功定義正式風格，一套外功只列一個正式風格。若某外功類別尚未定義風格，只標示外功類別，不自行創造第二套風格規則。
6. 招式名稱、連擊方式、擒拿傾向等已由條目效果表達的玩法描述，不另冒充第二類型。
7. 外功招式統一使用項目符號，每一招一行，格式為 `- 等級 招式名（成本，動作類型）：效果`。
8. 內功、輕功、藥物、裝備、敵人等可依自身欄位需要調整條目內容，但同一分檔群組必須保持一致，不可一檔用裸行標題、另一檔用 Markdown 標題。
9. 格式整理不得趁機改動機械數值、條件、效果或世界設定；若需要規則修訂，應另作明確規則變更。
