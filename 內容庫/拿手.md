# 拿手（Skill）

「拿手」是角色擅長處理的**檢定領域**。當一項行動與角色已熟練的拿手相符時，該次檢定加入熟練加值；若角色對該拿手具有「專精」，熟練加值改為加倍，同一判定最多加倍一次。

拿手不是特殊能力，也不是武學招式。它回答的是：「這件事是不是角色平日拿手的本領？」

建角時角色依角色建立規則選擇 4 項熟練拿手；背景、絕活或其他明確效果可以增加熟練或專精。

## 標準拿手

| 拿手 | 常用能力 | 常見用途 |
|---|---|---|
| 體能 | 力量 | 攀爬、游泳、破壞、長時間負重、角力 |
| 身法 | 敏捷 | 翻躍、平衡、脫身、穿越狹窄或危險地形 |
| 巧手 | 敏捷 | 扒竊、細小機關、藏物、精細手上操作 |
| 隱密 | 敏捷 | 潛行、藏身、偽裝行蹤、無聲接近 |
| 儒學 | 智力 | 經史、禮制、文士傳統、典故 |
| 道學 | 智力 | 道家典籍、儀軌、思想、相關江湖知識 |
| 佛學 | 智力 | 佛門典籍、戒律、寺院制度、相關江湖知識 |
| 信仰 | 智力或直覺 | 地方信俗、宗教習俗、辨識信仰行為與禁忌 |
| 歷史政治 | 智力 | 朝代、官制、地方政治、人物與事件沿革 |
| 天文地理 | 智力 | 方位、地形、氣候、星象、路線與區域知識 |
| 格物推理 | 智力 | 邏輯推演、機關原理、物證分析、數理與技術問題 |
| 醫毒藥理 | 智力 | 診傷、藥理、毒理、辨藥、治療與配製知識 |
| 識字 | 智力 | 閱讀、文書辨識、抄錄、辨認常見字體與格式 |
| 書畫 | 智力或敏捷 | 書法、繪畫、臨摹、辨識筆跡與技法 |
| 棋藝 | 智力 | 棋局、棋理、以棋交流或判斷棋手習慣 |
| 馴獸 | 直覺 | 安撫、驅使、照料、理解常見動物反應 |
| 洞察 | 直覺 | 判斷情緒、意圖、言行不一與社交異常 |
| 生存 | 直覺 | 追蹤、野外覓食、辨路、營地、天候與環境危險 |
| 感應 | 直覺 | 察覺細微聲息、危機、氣息變化與周遭異常 |
| 說服 | 魅力 | 談判、勸說、建立信任、提出交換 |
| 欺瞞 | 魅力 | 說謊、偽裝說辭、隱藏意圖、誤導 |
| 威嚇 | 魅力或力量 | 施壓、展示武力或氣勢、迫使對方重新衡量風險 |
| 表演 | 魅力 | 演說、戲曲、說書、舞藝及公開吸引注意 |
| 奏樂 | 魅力或敏捷 | 樂器演奏、辨識演奏技巧、以音樂交流 |
| 騎術 | 敏捷或直覺 | 騎乘、控制坐騎、急轉、躍障與安撫受驚坐騎 |

## 能力搭配
表中的能力只是常用搭配，不是固定綁定。若玩家的具體做法明顯更適合另一項能力，GM 可以改用不同能力搭配同一拿手。

例如：
- 用魁梧體格逼退對方：力量（威嚇）。
- 以理據與帳冊說服商人：智力（說服）。
- 靠多年山林直覺辨認草藥生長地：直覺（醫毒藥理）。

只有角色對該拿手熟練時才加入熟練加值；換能力不會取消拿手熟練。

## 新增拿手
如劇本或擴充內容確實需要新的長期拿手，應先確認它沒有被現有拿手合理涵蓋。新增條目至少寫明名稱、常用能力、適用範圍，以及與現有拿手的邊界，避免為單一場景創造過窄的新拿手。
