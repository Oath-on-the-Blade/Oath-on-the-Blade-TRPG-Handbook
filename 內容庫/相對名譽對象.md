# 相對名譽對象

本文件是《武與俠》**相對名譽**可使用對象的權威登錄表。相對名譽的計算與社交效果見 `遊玩規則/09_絕活名望與門派.md`；GM 如何在 NPC 互動中使用見 `GM規則/社會互動.md`。

劇本、GM、角色卡與結算**不得自行創造新的相對名譽數值對象**。若一份劇本需要讓某個新門派、官署、商會、幫派、地方組織或社會群體成為可跨劇本保存的相對名譽對象，必須先提出 Handbook 修訂，決定以下其一後才可正式使用：

1. 登錄為新的具名勢力；
2. 併入現有統一大類；
3. 把原本過大的大類拆成多個正式大類；
4. 認定只需敘事關係／人情／仇怨，不建立相對名譽數值。

單一劇本可以創造世界內 NPC、商號、地方機構與臨時團體，但在它們未登錄為本文件的正式對象前，只能用世界狀態、人情、恩義、仇怨、債務、承諾或其他已存在機制保存後果，不能自行寫「某某勢力相對名譽 +X」。

---

## 1. 對象規模與 c 值

相對名譽使用和歷練升級相同類型的線性逐級需求：

**升至相對名譽絕對值 x 級所需本級點數 = c × x + k**

- `x`：即將到達的相對名譽絕對值級別，從 1 開始；
- `c`：此對象的傳播規模／分散程度常數，由本文件為每個對象固定；
- `k`：全系統共用起始門檻，目前為 **4**；
- 劇本與 GM 不得改動某對象的 c 或 k。

相對名譽是可正可負的**淨點數**。正負互相抵銷；以淨點數的絕對值對照逐級需求，符號決定是正面或負面相對名譽。

`c` 越高，代表要改變整個對象的普遍看法需要更大、更多次或更廣泛傳播的事件。統一大類通常比單一具名勢力 c 更高。

建議尺度：

| 對象規模 | 常用 c | 說明 |
|---|---:|---|
| 小型、集中、資訊傳播快的具名組織 | 2 | 一個地方分舵、小型商會、緊密團體 |
| 一般大型具名門派／勢力 | 3 | 有多地成員但內部情報仍有穩定傳播 |
| 跨地區行業／社會圈大類 | 4 | 成員分散、沒有單一中樞 |
| 極廣泛制度／人口大類 | 5 | 例如整體官府、民間 |

以上是登錄時的設計基準，不授權劇本自行選 c。

## 2. 統一大類

以下大類是所有劇本可直接引用的正式相對名譽對象。

| 對象 | c | 涵蓋範圍 | 不自動涵蓋 |
|---|---:|---|---|
| **官府** | 5 | 地方衙門、巡檢、捕役、普通文武官署與朝廷體系的一般觀感 | 某個已另行登錄的特定官署／軍鎮；個別官員私交 |
| **民間** | 5 | 一般百姓、旅人、村鎮居民、無更合適專業圈身份者 | 商賈、士紳、黑道等已有專門大類 |
| **商賈** | 4 | 商人、店家、商隊、牙行、一般市會與合法買賣圈 | 已登錄的特定商會；專職走私者 |
| **士紳** | 4 | 地方望族、鄉紳、士人、富戶與依地方聲望行事的名流圈 | 官府本身；特定宗族若另行登錄 |
| **武林人士** | 4 | 無特定同門立場時的一般江湖武人、散修、比武圈與武林消息網 | 已登錄門派對本門利益的立場 |
| **鏢行護運** | 4 | 鏢師、護運人、車馬護衛、護送與保路行業圈 | 特定鏢局若另行登錄 |
| **草莽** | 4 | 無穩定官面身份、以地方武力／山野勢力生存的寨眾、綠林與地方武裝圈 | 組織化幫會黑道；專職走私網 |
| **幫會黑道** | 4 | 城鎮幫會、地盤勢力、地下秩序、勒索／灰色保護網等組織化黑道圈 | 純粹草莽；專業走私者 |
| **走私者** | 4 | 私運、黑市轉運、禁貨渠道、偷關越境與相關地下物流圈 | 一般合法商賈；所有黑道人物 |

### 2.1 同一 NPC 屬於多個圈時

NPC 可以客觀上同時具有多重身份，但**一次社交判定只選一個最相關相對名譽對象作機械修正**。

例：一名替商會走私的掌櫃，平日談合法貨價時可用【商賈】；玩家逼問禁貨路線時可用【走私者】。不能因同一 NPC 同時屬兩圈便把兩個相對名譽修正全部疊加。

若 NPC 同時屬一個正式具名勢力與一個統一大類，通常以**當前決策真正代表哪個立場**決定：
- 代表本門／本會／本署利益時，用具名勢力；
- 只以行業或社會身份作判斷時，用統一大類。

## 3. 正式具名門派

以下門派各自是獨立相對名譽對象；彼此不共用數值。除非後續 Handbook 另改，均使用 `c = 3`：

- 禪林寺
- 玄當派
- 赤煉宮
- 霜華閣
- 風雷殿
- 天嶽派
- 血影門
- 雲霧宗
- 百草閣
- 黃泉谷
- 鳳羽宮
- 天機閣
- 飛鷲派
- 刀狂谷
- 蒼龍門
- 鏡影閣

角色對其中一派的相對名譽，不自動改變其他門派的相對名譽；但同一公開事件可以由劇本結局對多個已登錄對象分別給出不同倍率，例如霜華閣上升、官府下降、武林人士略升。

## 4. 不等於相對名譽的資料

以下資料不應為了方便而新開一條相對名譽：

- 單一 NPC 對角色的私人喜惡；
- 一次性欠飯錢、醫藥費、賠償、承諾；
- 某人救命之恩或私人仇殺；
- 尚未在任何圈子傳開的秘密行為；
- 只有本 `game_id` 才存在的可重覆任務 NPC／商號／地點；
- 沒有跨劇本機械需要的純敘事「口碑」。

這些應使用 NPC 狀態、人情、恩義、仇怨、債務、懸賞、承諾、世界後果或江湖履歷保存。

---

## 5. 新增／合併／拆分要求

當劇本設計需要現有登錄表沒有的持久對象時，先提出 Handbook 修訂要求，至少說明：

- 候選名稱；
- 為何現有大類不足；
- 成員邊界與典型 NPC；
- 是否與既有大類／勢力重疊；
- 預計是具名勢力、統一大類，還是應拆分既有大類；
- 建議 c 及其規模理由；
- 至少兩種未來劇本中會實際引用此相對名譽的情境。

Handbook 核准並把條目加入本文件前，正式劇本不得預先使用該新數值名稱。
