# 《武與俠》 Oath on the Blade (OOTB) - TRPG

本 repository 分為五個主要模組：

- **世界知識庫/**：昊國的共用世界基準、政治地理、歷史、固定人物、門派、朝廷與江湖社會。
- **遊玩規則/**：玩家角色、判定、戰鬥、武學、成長與其他遊戲機制。
- **內容庫/**：可直接引用的拿手、絕活、武學、藥物、裝備與敵人條目。
- **GM規則/**：GM／AI GM 如何創角、主持、保存遊戲狀態、處理 NPC 與完成結算。
- **劇本設計規則/**：如何設計、檢查並交付可直接運行的完整 OOTB 劇本。

不同工作應先讀對應模組的 `README.md`，再按需要讀其子文件；不要把 GM 主持規則、劇本設計規則與玩家遊玩機制混成同一套文件。

AI／代理主持若需要控制上下文量，先讀 [`AI_GM讀取路由.md`](AI_GM讀取路由.md)，再進入各模組 README。
