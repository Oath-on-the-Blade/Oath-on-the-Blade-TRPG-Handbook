# Oath on the Blade (OOTB)

《武與俠》TRPG 的 GitHub 規則庫。核心 handbook 已按功能拆分；劇本仍維持「一劇本一檔完成」。

## AI / GM 讀取順序

主持遊戲時：

1. 讀取 [`規則/GM規則.md`](規則/GM規則.md)。
2. 讀取玩家提供的角色卡。
3. 讀取本次要運行的**完整劇本檔**；劇本可以來自 repo 外。
4. 按需要查閱 [`規則/`](規則/) 中的核心規則。
5. 按需要查閱 [`內容庫/`](內容庫/) 的武學、裝備、毒藥、藥物與敵人條目。

創作新劇本時，另讀 [`設計/劇本設計師規則.md`](設計/劇本設計師規則.md)。

## 重要原則

- **新建立的玩家角色一律由 1 級開始。**
- **既有玩家角色跨劇本持續使用**：不重置等級、能力、武學、裝備、銀兩、名望、聲譽、人情、勢力關係與長期特殊傷患。
- 玩家角色由玩家自帶；劇本不得要求每次重新創角。
- 玩家擲自己的角色骰；GM 在判定前說明使用能力、熟練、DC／對抗方式與可預見風險。
- 每個正式劇本原則上是一個可獨立運行的完整 `.md`；repo 中的劇本只作**參考劇本**。
- 世界基調為本格現實武俠：沒有客觀存在的仙、妖、鬼、神或魔法。超自然表象必須有心理、毒藥、機關、人為或武學等解釋。
- 武學可以超越現實物理，但必須來自既有武學體系，而不是無來源神通。
