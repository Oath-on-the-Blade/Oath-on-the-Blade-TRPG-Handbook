# 武器、護具與裝備基礎

**第七章　武器、護具與裝備**

## **1\. 武器基準**

| 武器 | 傷害 | 常用能力 | 特性   |
| :---- | :---- | :---- | :---- |
| 徒手 | 1d4 鈍擊 | 力量 | 拳掌武學可改寫 |
| 匕首 | 1d4 刺擊 | 敏捷 | 輕巧、可投 20/60 |
| 劍 | 1d8 斬劈或刺擊 | 敏捷或力量 | 外功劍法 |
| 刀 | 1d8 斬劈 | 力量 | 外功刀法 |
| 重刀 | 1d10 斬劈 | 力量 | 雙手 |
| 棍 | 1d6 鈍擊 | 力量 | 雙手時 1d8 |
| 槍／長兵 | 1d8 刺擊 | 力量 | 觸及 10 尺可作門派特例 |
| 弓 | 1d8 刺擊 | 敏捷 | 80/320 |
| 飛刀／暗器 | 1d4 刺擊 | 敏捷 | 30/90、可隱藏 |
| 重型暗器 | 1d6 刺擊 | 敏捷 | 20/60 |

第一個數字為正常射程，第二個為極限射程；極限射程攻擊有劣勢。

## **2\. 武器熟練**

角色建角時：

> * 熟練徒手  
> * 熟練 3 種自選常用武器  
> * 背景、門派或絕活可再增加

使用不熟練武器時，不加熟練加值。

## **3\. 物品與金錢**

本系統以「銀兩」作一般計價單位。若劇本不重視經濟，可以只記錄「貧乏／普通／富足」資源等級。  
建議起始：

> * 一套普通衣物  
> * 背景所選物品  
> * 1 件熟練武器  
> * 基本旅行包  
> * 10 兩銀

常見價格僅作劇本參考：普通餐食數錢、客棧一晚約半兩至一兩、普通兵器約 5–15 兩、良馬與名器遠高於此。
