# 角色建立與背景

**第一章　角色建立**

## **1\. 建角流程**

> 1. 決定角色概念、姓名、年齡與江湖目標。  
> 2. 選擇一個出身背景。  
> 3. 決定六項能力值。  
> 4. 選擇 4 項熟練特技。  
> 5. 選擇 2 項擅長豁免。  
> 6. 選擇 1 套主要內功。  
> 7. 選擇 1 套主要外功。  
> 8. 創建或選擇 1 套主要輕功。  
> 9. 選擇武器、護具與起始物品。  
> 10. 設定名望、聲譽、門派／勢力關係。  
> 11. 寫下至少一項信念、一項牽掛與一項長期目標。

## **2\. 六項能力值**

### **力量（Strength）**

爆發力、負重、推拉、重兵器、剛猛拳掌、強行格擋。

### **敏捷（Dexterity）**

身法、反應、潛行、暗器、輕靈武學、輕功。

### **體質（Constitution）**

氣血、耐力、抗毒、疲勞、維持運功。

### **智力（Intelligence）**

學問、機關、醫毒、推理、武學理論。

### **直覺（Sense）**

察覺、洞察、危機感、修心、感應、野外經驗。

### **魅力（Charisma）**

說服、威嚇、欺瞞、領導、江湖氣場。

### **能力值生成**

預設使用標準陣列：**15、14、13、12、10、8**，自由分配。  
可選擲骰：每項擲 4d6，捨棄最低一顆，六組結果再自由分配。

### **能力修正值**

修正值 \= floor((能力值 \- 10\) / 2)。

| 能力值 | 修正   |
| ----: | ----- |
| 8–9 | \-1 |
| 10–11 | \+0 |
| 12–13 | \+1 |
| 14–15 | \+2 |
| 16–17 | \+3 |
| 18–19 | \+4 |
| 20 | \+5 |

一般能力上限為 20；特殊武學或傳奇效果才可突破。

## **3\. 熟練加值**

| 角色等級 | 熟練加值   |
| :---- | ----- |
| 1–4 | \+2 |
| 5–8 | \+3 |
| 9–12 | \+4 |
| 13–16 | \+5 |
| 17–20 | \+6 |

熟練加值用於：

> * 熟練特技  
> * 熟練武器攻擊  
> * 擅長豁免  
> * 內功攻擊與內功 DC  
> * 外功招式要求的武學檢定

「專精」代表熟練加值加倍，同一判定最多加倍一次。

## **4\. 衍生數值**

### **氣血上限**

1 級：8 \+ 體質修正值。  
2 級起每升一級：

> * 擲 1d8 \+ 體質修正值 增加氣血上限；或  
> * 使用固定值 5 \+ 體質修正值。

每級至少增加 1 點。

### **氣血骰**

角色擁有等同角色等級數量的 **d8 氣血骰**。短休時可消耗氣血骰療傷。部分內功也會消耗或恢復氣血骰。

### **防禦 AC**

> * 無甲：10 \+ 敏捷修正值  
> * 輕甲：11 \+ 敏捷修正值  
> * 中甲：13 \+ 敏捷修正值（最多 \+2）  
> * 重甲：16  
> * 盾／大型格擋器具：通常 \+2 AC

同類護具不疊加。武學提供的 AC 加值依招式敘述處理。

### **先攻**

1d20 \+ 敏捷修正值。

### **基礎步速**

30 尺／回合。種族或體型差異若有需要，由團隊在建角時約定。

### **被動察覺**

10 \+ 直覺修正值 \+ 熟練加值（若熟練感應或相關特技）。

## **5\. 豁免**

建角時選擇兩項能力作為「擅長豁免」。  
豁免： 1d20 \+ 對應能力修正值 \+ 熟練加值（若擅長）  
常見：

> * 力量：抗推、抗擒拿  
> * 敏捷：避開範圍攻擊、陷阱  
> * 體質：抗毒、疲勞、維持專注  
> * 智力：識破複雜幻術、精神推演  
> * 直覺：抗恐懼、迷惑、感官干擾  
> * 魅力：抵抗意志壓迫、身份／靈魂類影響

**第二章　出身背景**

## **1\. 背景規則**

預設只選一個背景。  
每個背景提供：

> * 1 個固定能力加值 \+1  
> * 從兩項候選中選 1 項 \+2  
> * 從該背景的「背景特性／物品／資源」中選 **3 項**

若團隊容許混合背景，可混合 2–3 個背景，但最後仍只得到：

> * 一個固定 \+1  
> * 一個候選 \+2  
> * 三項背景利益

同一能力值在建角後通常不得高於 17。

## **2\. 標準背景**

### **門派子弟**

固定：體質 \+1；候選：力量 \+2 或 智力 \+2。 可選利益：

> * 武學基礎：額外熟悉一門初階武學；若該武學已是主要武學，第一次相關學習檢定有優勢。  
> * 門派資源：在己方勢力範圍內取得基本食宿與庇護。  
> * 人脈廣博：與正規武林勢力交涉時，合適情況獲優勢。  
> * 初級武器與護具。  
> * 一份門派秘藥。

### **江湖遊俠**

固定：敏捷 \+1；候選：直覺 \+2 或 智力 \+2。 利益：匿蹤高手、察言觀色、隨機應變、靈活輕甲／靴、江湖生存包。

### **無依孤兒**

固定：體質 \+1；候選：力量 \+2 或 敏捷 \+2。 利益：強健體魄、野外生存、天賦直覺、生存工具包、殘缺初級秘笈。

### **朝廷屬下**

固定：力量 \+1；候選：體質 \+2 或 智力 \+2。 利益：武器精通、官府背景、鎮壓者、官製武器、官製護甲。

### **富家子弟**

固定：智力 \+1；候選：魅力 \+2 或 直覺 \+2。 利益：財力支持、商業頭腦、上流人脈、名器、推薦信。

### **流浪武者**

固定：力量 \+1；候選：體質 \+2 或 敏捷 \+2。 利益：武學天賦、武道精進、低調無名、精良武器、江湖生存包。

### **隱居奇人**

固定：魅力 \+1；候選：智力 \+2 或 直覺 \+2。 利益：奇門遁甲、深山隱居、低調無名、野外工具包、雜學典籍。

### **毒血之人**

固定：智力 \+1；候選：敏捷 \+2 或 體質 \+2。 利益：毒物精通、毒性抗體、出其不意、毒與解毒工具包、淬毒武器。

### **求道之士**

固定：智力 \+1；候選：魅力 \+2 或 體質 \+2。 利益：修心養性、悟道之術、冥思修行、古經、護符／法器。

### **江湖後裔**

固定：魅力 \+1；候選：力量 \+2 或 體質 \+2。 利益：武學基礎、武學天賦、武器精通、傳承武器／護具、推薦信。

### **風野之民**

固定：體質 \+1；候選：力量 \+2 或 直覺 \+2。 利益：騎術專精、野外生存、風中靈敏、良馬、野外工具包。

### **異域來客**

固定：魅力 \+1；候選：智力 \+2 或 敏捷 \+2。 利益：異國風情、出其不意、多國語言、異國武器、異國典籍。

### **凡俗之民**

固定：體質 \+1；候選：力量 \+2 或 智力 \+2。 利益：生活智慧、低調無名、商業頭腦、實用工具／武器、小額資金。
