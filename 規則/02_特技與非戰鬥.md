# 特技、檢定與非戰鬥行動

**第三章　特技、檢定與非戰鬥行動**

## **1\. 特技**

建角時選 4 項熟練特技。背景或專長可增加。  
標準特技及常用能力：

> * 體能（力量）：攀爬、游泳、破壞、長時間負重  
> * 身法（敏捷）：翻躍、平衡、脫身  
> * 巧手（敏捷）：扒竊、細小機關、藏物  
> * 隱密（敏捷）：潛行、偽裝行蹤  
> * 儒學（智力）  
> * 道學（智力）  
> * 佛學（智力）  
> * 信仰（智力或直覺）  
> * 歷史政治（智力）  
> * 天文地理（智力）  
> * 格物推理（智力）  
> * 醫毒藥理（智力）  
> * 識字（智力）  
> * 書畫（智力或敏捷）  
> * 棋藝（智力）  
> * 馴獸（直覺）  
> * 洞察（直覺）  
> * 生存（直覺）  
> * 感應（直覺）  
> * 說服（魅力）  
> * 欺瞞（魅力）  
> * 威嚇（魅力或力量）  
> * 表演（魅力）  
> * 奏樂（魅力或敏捷）  
> * 騎術（敏捷或直覺）

如果行動明顯更適合另一能力，GM 可改用不同能力搭配同一特技，例如「力量（威嚇）」。

## **2\. 對抗檢定**

雙方各擲相關檢定，較高者勝。平手時維持現狀。  
常見：

> * 擒拿：力量（體能）對力量（體能）或敏捷（身法）  
> * 隱藏：敏捷（隱密）對被動察覺  
> * 欺瞞：魅力（欺瞞）對直覺（洞察）

## **3\. 團體檢定**

半數或以上成員成功，團體視為成功。若一名角色可以合理帶領全隊，可讓該角色判定並給其他人優勢／減輕失敗後果。

## **4\. 調查資訊**

關鍵資訊不應只鎖在單次成功判定後。合理查看即可得到最低限度資訊；成功判定帶來更完整、更快、更安全的資訊。
