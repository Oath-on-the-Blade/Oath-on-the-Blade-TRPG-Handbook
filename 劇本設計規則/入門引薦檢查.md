# 劇本設計規則：門派入門引薦檢查

本文件只檢查**最終劇本 md**。只要劇本把任何正式門派的：

`〈門派〉引薦｜可宣告使用以申請入門｜未使用`

列為角色可取得獎勵，就必須在一般 `檢查.md → 拿手檢查.md → 社會名譽檢查.md → 整備檢查.md` 全部通過後，再執行本文件。

先判斷本篇屬於哪一種情況：

- **A｜一般引薦獎勵**：原本是一般、關連、高難度、戰役階段、普通可重覆或其他合法類型，只是在合適條件下把引薦列為獎勵；
- **B｜門派引薦可重覆任務**：本篇的主要設計目的之一，就是讓未入門角色透過新的可重覆世界事件反覆爭取／重新取得引薦機會。

兩者都使用本檢查，但**B 是保留的正式專門類型；A 不會因有引薦而被改成 B。**

任一硬性項目失敗，該引薦獎勵／專門引薦任務不得交付為完成狀態。

---

## 1. 類型判定硬檢

### 1.1 一般引薦獎勵

若本篇不是專門的門派引薦可重覆任務：

- [ ] 沒有只因加入引薦，就把 `once_per_character` 改成 `repeatable`。
- [ ] 沒有只因加入引薦，就改變連續性、建議等級、R、劇本規模、難度、關連樹或其他原定位。
- [ ] 檔名前綴仍跟原底層任務類型走。
- [ ] 若本篇是關連節點，仍保留原關連來源、樹與 state；沒有因引薦退出／更換關連樹。

### 1.2 門派引薦可重覆任務

若本篇正式定位為**門派引薦可重覆任務**：

- [ ] 規格頭明列 `任務類別：門派引薦可重覆任務（非門派專用任務）`。
- [ ] `運行類別：可重覆任務`。
- [ ] `replay_policy: repeatable`。
- [ ] `連續性：independent`。
- [ ] `劇本規模：小型`。
- [ ] `重跑基型：兩者`（日常可再發生＋小型分支）。
- [ ] 正式檔名使用 `OOTB_門派引薦可重覆任務_<劇名>.md`。
- [ ] 本篇確實以「新的可重覆世界事件提供新的引薦機會」為主要目的之一，不是只因普通可重覆任務順帶有一項引薦，就硬改用專用前綴。
- [ ] 已另完整通過 `可重覆任務檢查.md`。

**失敗條件**：一般／關連任務因有引薦被強制轉類型；或反過來，明明是專門引薦可重覆任務卻缺少其正式類型資料。

---

## 2. 引薦是否真的適合本篇硬檢

最終 md 必須能直接回答：

- [ ] 角色做了甚麼，足以令目標門派願意替其入門申請背書？
- [ ] 這項行動為何與該門派理念、收徒標準、能力需求、責任或關係有關？
- [ ] 誰知道角色做了這件事？
- [ ] 哪個結局／哪些 state 才能取得？
- [ ] 個人參與條件足以排除只在終局掛名領獎的人？

若唯一理由只是「幫過門派」「普通門人喜歡角色」「事件發生在山門附近」，即不通過。

---

## 3. 角色資格與替代獎勵硬檢

- [ ] 尚未加入目標門派、且沒有同派有效引薦的合資格角色可以取得。
- [ ] 已是目標門派正式成員者不能再取得本派引薦。
- [ ] 已持有同一門派有效未使用引薦者不能取得第二份。
- [ ] 引薦是個人獎勵時，至少另有一項已預寫的個人替代獎勵。
- [ ] 已是門人、已有有效引薦或不想取引薦者，仍可正常取得替代獎勵。
- [ ] 替代獎勵有具體內容、交付者與交付狀態，不是「GM 另給合理補償」。
- [ ] 沒有把引薦換算成固定銀兩買價。
- [ ] 不同角色可各自選擇；若世界內有限額，原因與名額已預先成立，未取得者仍有完整替代獎勵。

任一不通過即失敗。

---

## 4. 發薦來源與權限硬檢

- [ ] 目標門派是 Handbook 正式存在的具名門派。
- [ ] 最終 md 有具體人物或制度負責發出／批准引薦。
- [ ] 該人物／制度真的有合理權限，不是普通門人因一時欣賞便自行代表全派。
- [ ] 若遞交者不是批准者，正文清楚分開遞交與批准權。
- [ ] 使用最低足夠組織層級，沒有為普通事件硬拉掌門／首領親自出場。
- [ ] 本次角色的實際行動與發薦理由可直接連起來。

若本篇不是可重覆任務：

- [ ] 可依世界知識正常使用本篇具名 NPC、固定世界人物或門派制度；沒有套用不屬本篇的可重覆固定人物限制。

若本篇是任何可重覆任務，包括門派引薦可重覆任務：

- [ ] 發薦 NPC、地點、事件與其他實例資料仍完整符合 `可重覆任務檢查.md`；沒有因引薦而豁免新 `game_id` 實例化、變體或固定人物限制。

任一不通過即失敗。

---

## 5. 角色卡寫回與個人歸屬硬檢

引薦成立時，GM 必須可直接寫回：

`〈門派〉引薦｜可宣告使用以申請入門｜未使用`

並確認：

- [ ] 引薦屬於哪名角色本人。
- [ ] 不可轉讓、出售、贈送或作隊伍共有。
- [ ] 同一角色同一門派同時最多一份有效引薦。
- [ ] 一份引薦只支援一次正式入門申請。
- [ ] 引薦本身不保證入門成功。

---

## 6. 取得次數與 `replay_policy` 硬檢

共同檢查：

- [ ] 已是門人者不能取得同派新引薦。
- [ ] 正持有有效引薦者不能取得第二份。
- [ ] 引薦不可轉讓、出售、共享或疊加成額外入門修正。

### 6.1 `once_per_character`

- [ ] 沒有因入門失敗而允許角色重跑同一 `script_id` 刷第二份引薦。
- [ ] 「日後可重新取得引薦」沒有被偷寫成同一篇的重跑權。
- [ ] 日後若要再申請，只能由另一份合法劇本／正式來源取得新引薦。

### 6.2 一般 `repeatable` 任務附帶引薦

- [ ] 已另完整通過 `可重覆任務檢查.md`。
- [ ] 同一 `game_id` 不得重領、補領第二份或藉不同 `variant_id` 重覆取得。
- [ ] 已使用且失敗／失效後，只能在新的 `game_id` 再次完整參與並符合發薦條件時重新取得。
- [ ] 引薦只是本篇其中一項獎勵時，沒有無理由改用 `OOTB_門派引薦可重覆任務_` 專用前綴。

### 6.3 門派引薦可重覆任務

除 6.2 外再確認：

- [ ] 新 `game_id` 是另一宗世界事件，不是上一宗倒帶。
- [ ] 至少有 2 個正式 `variant_id`，且第一條有意義線索前已鎖定。
- [ ] 新局重新實例化可變 NPC、專用 LOC、PROP／CLUE；同局保持映射。
- [ ] 本類的主要重跑價值確實是新的引薦機會，而不是把同一事件重置。
- [ ] 歷練、現銀、正向名譽、永久物品與其他可累積獎勵另有明確重覆上限。

**失敗條件**：把所有含引薦劇本都視為 repeatable；或專門類型沒有真正的新事件與防刷結構。

---

## 7. 關連任務引薦硬檢

若本篇是跨劇本關連節點：

- [ ] 引薦由本篇自己的事件、人物／制度與結局建立，不是只因「前作幫過該門派」便自動發出。
- [ ] 會影響引薦資格的前作 `ending_id`／state 已按 `跨劇本關連設計.md` 明列可執行效果。
- [ ] 前作不是必要前置時，無前作紀錄仍有完整基線。
- [ ] 引薦只寫入取得角色自己的持久狀態，不升格成整棵樹共同 state。
- [ ] 關連樹目錄若提及引薦，只作條件索引；其他角色／節點不自動繼承。
- [ ] 沒有因引薦要求樹內節點同等級、同 R、同難度或同獎勵結構。
- [ ] 若該關連節點本身另是門派引薦可重覆任務，兩套專項邊界均有完整處理；沒有以關連名義繞過可重覆前置隔離。

任一不通過即失敗。

---

## 8. 不得偷渡入門、武學、配給或名譽

單純取得引薦時，確認沒有同時自動：

- [ ] 成為門派成員；
- [ ] 通過入門判定；
- [ ] 取得門派免費整備配給；
- [ ] 取得任何 `[來自〈門派〉]` 武學來源；
- [ ] 提高任何武學解鎖上限；
- [ ] 取得內門／真傳／職位；
- [ ] 因「得到引薦」本身直接增加門派相對名譽。

若劇本另外真正授予門派武學，必須再完整通過 `門派武學檢查.md`。

---

## 9. 社會名譽沿用底層任務類型硬檢

- [ ] 一般／一般關連任務仍按一般劇本 `E × r_T`。
- [ ] 真正門派專用任務仍使用其原有門派相對名譽公式 `R × m`，不因引薦改變。
- [ ] 一般可重覆任務的正向名譽重覆上限仍按正文。
- [ ] **門派引薦可重覆任務不是門派專用任務**，使用一般可重覆任務 `E × r_T` 與其正向上限，不套 `R × m`。
- [ ] 取得引薦本身不是加相對名譽的原因。
- [ ] 所有非零名譽變化仍有事件、傳播與可靠歸因支持。

---

## 10. 檔名硬檢

### 一般引薦獎勵

- [ ] 一般、關連、高難度、戰役階段或普通可重覆任務，只因附帶引薦時，仍使用原底層類型的正式檔名前綴。

### 門派引薦可重覆任務

- [ ] 專門類型使用 `OOTB_門派引薦可重覆任務_<劇名>.md`。
- [ ] 沒有因「其他任務也能給引薦」而移除這個保留類型或強制把其既有合法檔案改成普通前綴。
- [ ] 沒有反過來把所有含引薦的任務都強制套這個前綴。

---

## 11. 最終可直接交付

最後只看最終 md，GM 必須能直接回答：

`底層任務類型／replay_policy｜是否為門派引薦可重覆任務｜目標門派｜哪些結局可得引薦｜誰有資格｜替代獎勵｜誰批准｜為何願意背書｜角色卡如何寫｜引薦能做甚麼／不能做甚麼｜once_per_character 時能否重拿｜repeatable 時何時可在新 game_id 再取｜若是關連節點前作 state 如何影響｜社會名譽按哪個底層類型結算`

只要任何答案仍是「GM 自行決定」「完成就算入門」「入門失敗就重跑同一篇」「有引薦所以自動變專門類型」「專門類型存在所以其他劇本不能給引薦」，即不通過。
