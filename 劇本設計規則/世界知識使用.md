# 劇本設計規則：世界知識使用

本文件規範正式劇本如何引用 `世界知識庫/`。世界知識庫本身只保存共用世界事實；所有「劇本可以怎樣新增／改變」「GM 怎樣使用」「機械如何結算」均不在世界知識庫內定義。

## 1. 共用基準與劇本局部真相

正式劇本以 `世界知識庫/` 當前記載的國號、年代、政治地理、固定人物、組織、歷史、公開關係與刻意未知作共用起始基準。

### 1.1 面向文件與實體權威

`地理與世界基準/`、`人文/`、`政治/`、`江湖/` 負責描述世界面向、制度與整體狀態；`組織/`、`人物/` 負責具名實體的唯一權威資料。劇本若實際使用固定人物或具名組織，**不能只讀面向總覽或 README 索引**，必須讀該人物／組織的單一權威檔。

面向總覽中的連結、比較與概括不能取代實體檔；若兩者意外出現衝突，應先修 Handbook，未修前不得由劇本自行挑選有利版本。

劇本可以在不衝突的空白位置建立**本劇本局部真相**，例如：
- 某道內的縣、村、渡口、山莊、地方商號、工坊、樓館、鏢站、幫會堂口或普通分舵；
- 未被固定姓名的地方官、掌櫃、弟子、頭目、鏢師、工匠、富戶與其他 NPC；
- 不改變既有大歷史骨架的地方舊案、災難、婚盟、比武、恩怨、支派事件與近年傳聞。

局部新增不得反向改寫已固定的國號、年號、十道邊界、主要山川位置、首都、正式門派山門、固定人物姓名／外號／生死、現任首領、祖師、已固定武學源流或其他明確世界事實。

若使用者明確要求修改 Handbook 共用正典，應先作世界知識庫修訂；不能把單一劇本的局部真相冒充成已完成的共用正典修改。

## 2. 刻意未知與秘密

`世界知識庫/` 明寫「真名不詳」「身份不詳」「下落不明」「沒有可靠證據」「沒有公開固定總壇」等內容時，表示共用基準**沒有被固定的唯一答案**。

劇本可以：
- 揭穿某次冒名；
- 提供一名候選身份；
- 確定某一地方據點、代理人、支線事件或該 `game_id` 的局部答案；
- 讓角色取得比一般人更可靠的證據。

劇本不得在沒有 Handbook 正典修訂的情況下，無限定宣告已解開整個共用世界的唯一真名、唯一總壇、唯一幕後身份或其他刻意保留未知。

## 3. 固定母勢力與隱藏隸屬

劇本可新增商會旗下分號／工坊／樓館、鏢局分局／鏢站、幫會堂口／香堂、門派地方別院或其他下屬單位。

若「表面獨立，其實隸屬某固定母勢力」是劇情揭密，**真實隸屬必須在最終劇本的 GM 真相中於開局前固定**，並提供可追查的世界內線索。不能到玩家調查後才由 GM 按方便、角色名譽高低或臨場需要決定它屬於誰。

普通新增子單位不因此自動成為新的相對名譽對象；相對名譽是否存在及其正式對象只依 `內容庫/相對名譽對象.md`。

## 4. 固定人物與組織登場

引用世界知識庫固定人物時，人物權威檔只提供共用背景，不能取代本劇本運行資料。最終劇本仍須寫出該人物在本事件中的：
- NPC 識別；
- 當前認知與誤解；
- 目的與利益；
- 所需數值／正式能力引用；
- 場景行動、下一步與可預見後果。

固定人物、門派、官署、商會、鏢局、幫會或政治組織都不是完全同步的單一人格。若劇本要讓其中一名成員、地方堂口或內部派系違背公開立場，須把責任落到具體人物／支部及其資源與動機；不能用一個局部陰謀無條件改寫整個組織的共用基準。

## 5. 地理、路程與地方新增

新增地點至少要能判定其所屬道、鄰近大城／官道／水路、主要地貌、常見生計與到達方式。

世界知識庫列出的基準路程可以因洪水、封關、戰亂、追逐、捷徑、船速、特殊交通或其他世界內原因改變；劇本若依賴明顯偏離基準的時間，須把原因與實際路線寫入正文。不能把原本相隔數道的固定地點無理由改成步行半日可達。

## 6. 角色知道甚麼

世界知識庫是作者／GM 使用的客觀共用基準，**不等於所有 PC 開局全知**。

劇本須依角色出身、已公開名氣、所屬組織、拿手、既有經歷、消息來源與場景線索，決定哪些世界事實可直接知道、哪些需要詢問／查證／判定、哪些仍不可得知。不能因某事寫在世界知識庫便直接把秘密塞給所有角色，也不能把當地常識故意藏成無提示難題。

## 7. 獨立劇本與連續戰役

獨立劇本預設使用世界知識庫的共同基準時點，再加入本劇本局部真相。

連續戰役則承接該 `game_id`／戰役最新有效存檔。若既有遊戲已造成固定人物死亡、門派易主、山門／城市損毀、公開結盟或其他持續變化，後續劇本必須明寫承接來源與開場狀態；不能由世界知識庫基準把已發生結果重置。

單一桌次造成的變化只屬其持續世界狀態，除非另作 Handbook 正典修訂，不自動改寫其他獨立劇本的共同起點。

## 8. 世界事實、機械與主持分工

- 世界中存在甚麼、人物是誰、組織關係與歷史如何：查 `世界知識庫/`。
- 判定、戰鬥、成長、裝備、社會名譽等遊戲機械：查 `遊玩規則/` 與 `內容庫/`。
- GM 在實際遊戲中如何載入、隱藏、揭露與保存資料：查 `GM規則/`。
- 劇本如何新增局部真相、引用共用正典並交付：依本目錄規則。

世界知識庫中的「天下聞名」「宗師」「最著名」「大勢力」等世界描述不會自行產生額外 AC、氣血、攻擊加值、武學等級、相對名譽 `c` 或其他未在正式規則中定義的機械效果。
