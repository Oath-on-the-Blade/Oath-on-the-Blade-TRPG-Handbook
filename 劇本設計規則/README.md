# 劇本設計規則

本目錄規範如何製作一份可直接交給 GM 運行的《武與俠》TRPG 劇本，並把「創作」與「驗收」分成兩個工作階段。

## Phase A：設計

先完整讀取：
- [`設計.md`](設計.md)

若打算把劇本設計成、或最終規格頭明列：
- `運行類別：可重覆任務`

則必須再完整讀取：
- [`可重覆任務設計.md`](可重覆任務設計.md)

若劇本任何必要線索、真相、文書或姓名機關依賴漢字字形、拆字、形近字、姓名文字、同音／近音、諧音、口音、聲調或誤聽，則必須再完整讀取：
- [`文字機關設計.md`](文字機關設計.md)

若同一劇本同時屬「可重覆任務」與「文字機關」，兩份補充規格同時適用。`文字機關設計.md` 只在**姓名欄位為已預寫文字機關不可替代資料**時，提供「最小固定姓名欄位」窄範圍例外；可重覆任務的事件重現、`LOC#`、新 `game_id` 新人物、`variant_id`、獎勵上限及其他規格不因此放寬。

再按需要查閱：
- `遊玩規則/`
- `內容庫/`
- 若需要理解 GM 如何在實際遊戲中處理某種資料，再讀 `GM規則/README.md` 及其指定子文件；可重覆任務另須遵守 `GM規則/可重覆任務.md`；文字機關另須遵守 `GM規則/文字機關.md`。

設計階段負責：交付形式、規格頭、世界真相、時間線、NPC、跨劇本關係、線索、場景、遭遇、危機、獎勵、歷練、終局、偏離處理及可直接運行的細節。

`可重覆任務設計.md` 是該運行類別的**加嚴補充規格**；只在該類別內適用。一般劇本不因規模小、NPC 名稱可變或情節簡單而自動取得重跑資格。

`文字機關設計.md` 是所有使用必要文字／讀音機關劇本的**專項補充規格**。凡依賴讀音推理，最低必須考慮普通話／國語與粵語使用者；不能把只在普通話成立的諧音當成唯一通關鑰匙而沒有粵語平行提示或非讀音冗餘路徑。

### 可重覆任務的檔名

正式發布／存入 Community Scripts 的可重覆任務，檔名前綴統一使用：
- `OOTB_可重覆任務_<劇名>.md`

此命名與既有 `OOTB_初期任務_<劇名>.md` 的任務層級一致；**不得使用 `OOTB_可重覆劇本_<劇名>.md` 或 `OOTB_可重覆小型副本_<劇名>.md` 作正式檔名**。

「可重覆任務」是正式運行類別名稱；任務是否屬小型，另由規格頭 `劇本規模：小型` 約束，不把「小型」寫入類別名稱。

## Phase B：檢查

初稿完成後，**把設計過程視為不存在，只拿最終劇本 md**，再完整讀取：
- [`檢查.md`](檢查.md)

若最終劇本明列：
- `運行類別：可重覆任務`

則在一般檢查全部完成後，再完整讀取並執行：
- [`可重覆任務檢查.md`](可重覆任務檢查.md)

若最終劇本含必要文字／讀音機關，再完整讀取並執行：
- [`文字機關檢查.md`](文字機關檢查.md)

若同時是可重覆任務與文字機關，三層檢查順序為：
1. `檢查.md`
2. `可重覆任務檢查.md`
3. `文字機關檢查.md`

其中 `可重覆任務檢查.md` 的「不得固定姓／名」項，對最終 md 已依 `文字機關設計.md` 明確證明為必要、且通過 `文字機關檢查.md` 的**最小固定欄位**不作失敗判定；其他 NPC／其他欄位仍按全可變要求驗收。

檢查階段負責：完成品／大綱判定、格式硬檢、反交付／反大綱閘門、偏離覆檢及發布前驗收；可重覆任務另加驗事件可重現性、NPC 實例化、實例識別、真相分支鎖定及重複獎勵上限；文字機關另加驗世界內成因、字形／讀音實際可用性、普通話／粵語可達性及姓名最小固定合理性。

只要 `檢查.md` 任一硬性項目不通過，就必須回到劇本正文補完，再重新檢查；不得以「GM 到時自行補」「作者心裡知道」「理論上可有其他線索」視為通過。

若屬「可重覆任務」，`可重覆任務檢查.md` 任一硬性項目不通過亦不得交付為該類別；只能回正文修正後重檢，或移除該類別並按一般 `once_per_character` 劇本處理。

若含必要文字／讀音機關，`文字機關檢查.md` 任一硬性項目不通過亦不得交付；不能把語音差異、粵語版本或姓名固定理由留給 GM 臨場補。

## 權威邊界

- **遊戲機制是甚麼**：`遊玩規則/`
- **可引用內容是甚麼**：`內容庫/`
- **GM 如何運行**：`GM規則/`
- **一般劇本如何設計**：本目錄 `設計.md`
- **可重覆任務如何設計**：本目錄 `可重覆任務設計.md`（只在該類別加嚴適用）
- **文字／讀音機關如何設計**：本目錄 `文字機關設計.md`
- **一般劇本是否合格可交付**：本目錄 `檢查.md`
- **可重覆任務是否合格可交付**：先通過 `檢查.md`，再通過 `可重覆任務檢查.md`
- **文字／讀音機關是否合格**：另通過 `文字機關檢查.md`

同一規則不應在多個模組各自建立不同版本。若 `設計.md` 或類別補充規格要求某資料供 GM 使用，GM 的實際運行行為仍以 `GM規則/` 的權威主持流程為準。
