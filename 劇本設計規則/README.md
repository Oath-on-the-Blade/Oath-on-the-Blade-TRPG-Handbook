# 劇本設計規則

本目錄規範如何製作一份可直接交給 GM 運行的《武與俠》TRPG 劇本，並把「創作」與「驗收」分成兩個工作階段。

## Phase A：設計

先完整讀取：
- [`設計.md`](設計.md)
- [`社會名譽設計.md`](社會名譽設計.md)

`社會名譽設計.md` 是所有正式劇本共通規格。即使某份劇本不預定給予俠名、惡名或相對名譽，也必須確認既有角色的名氣／名譽是否會合理影響 NPC；若確實完全無關，正文可明寫無社會名譽變化／無名譽門檻。劇本不得沿用舊制 `名望／聲譽／勢力關係／口碑 +1`，亦不得自行建立新的相對名譽對象。

若打算把劇本設計成、或最終規格頭明列：
- `運行類別：可重覆任務`

則必須再完整讀取：
- [`可重覆任務設計.md`](可重覆任務設計.md)

若**當前劇本本身不是可重覆任務，但與一份可重覆任務宣告前傳、後傳、平行、承接、前置或其他跨劇本關連**，仍必須讀取：
- [`可重覆任務設計.md`](可重覆任務設計.md) 的 **4.1「跨劇本前置隔離」**。

此時只因「跨劇本關連」而觸發的部分，不會把當前一般劇本自動變成可重覆任務；但**不得把可重覆任務作必要前置基礎**的規則仍是硬性規格。

若劇本任何必要線索、真相、文書或姓名機關依賴漢字字形、拆字、形近字、姓名文字、同音／近音、諧音、口音、聲調或誤聽，則必須再完整讀取：
- [`文字機關設計.md`](文字機關設計.md)

若同一劇本同時屬「可重覆任務」與「文字機關」，兩份補充規格同時適用。`文字機關設計.md` 只在**姓名欄位為已預寫文字機關不可替代資料**時，提供「最小固定姓名欄位」窄範圍例外；可重覆任務的事件重現、`LOC#`、`PROP#`／`CLUE#`、新 `game_id` 新人物、`variant_id`、獎勵上限及跨劇本前置隔離不因此放寬。

再按需要查閱：
- `遊玩規則/`
- `內容庫/`；若涉及社會名譽，正式相對名譽對象必須查 `內容庫/相對名譽對象.md`
- 若需要理解 GM 如何在實際遊戲中處理某種資料，再讀 `GM規則/README.md` 及其指定子文件；社會互動另讀 `GM規則/社會互動.md`；可重覆任務另須遵守 `GM規則/可重覆任務.md`；文字機關另須遵守 `GM規則/文字機關.md`。

設計階段負責：交付形式、規格頭、世界真相、時間線、NPC、跨劇本關係、線索、場景、遭遇、危機、獎勵、歷練、俠名／惡名／名氣／相對名譽、終局、偏離處理及可直接運行的細節。

`社會名譽設計.md` 是所有劇本的**共通社會系統規格**；俠名與惡名以本次實得基礎歷練倍率增加、名氣由兩者總和推導、相對名譽只可引用 Handbook 已登錄對象。劇本若需要新勢力／大類，必須先修 Handbook，不得把新數值藏在單一劇本。

`可重覆任務設計.md` 是該運行類別的**加嚴補充規格**；一般劇本不因規模小、NPC 名稱可變、地點可變、關鍵道具／線索表象可變或情節簡單而自動取得重跑資格。可重覆任務除了 NPC／LOC 外，關鍵 `PROP#`／`CLUE#` 的**非必要固定形態**也須在新 `game_id` 重新實例化；若形態會改變機械或因果，必須預寫差異或升格成 `variant_id`。

`文字機關設計.md` 是所有使用必要文字／讀音機關劇本的**專項補充規格**。凡依賴讀音推理，最低必須考慮普通話／國語與粵語使用者；不能把只在普通話成立的諧音當成唯一通關鑰匙而沒有粵語平行提示或非讀音冗餘路徑。

### 可重覆任務的檔名

正式發布／存入 Community Scripts 的可重覆任務，檔名前綴統一使用：
- `OOTB_可重覆任務_<劇名>.md`

此命名與既有 `OOTB_初期任務_<劇名>.md` 的任務層級一致；**不得使用 `OOTB_可重覆劇本_<劇名>.md` 或 `OOTB_可重覆小型副本_<劇名>.md` 作正式檔名**。

「可重覆任務」是正式運行類別名稱；任務是否屬小型，另由規格頭 `劇本規模：小型` 約束，不把「小型」寫入類別名稱。

## Phase B：檢查

初稿完成後，**把設計過程視為不存在，只拿最終劇本 md**，先完整讀取並執行：
- [`檢查.md`](檢查.md)

所有正式劇本在一般檢查完成後，**必須再完整讀取並依序執行**：
- [`拿手檢查.md`](拿手檢查.md)
- [`社會名譽檢查.md`](社會名譽檢查.md)

`拿手檢查.md` 是所有劇本共通的拿手與非戰鬥判定硬檢；即使劇本只引用了拿手規則、只使用少量非戰鬥判定，或自稱主要以戰鬥／追逐為主，也不能跳過。它會檢查正式拿手名稱、能力＋拿手搭配、熟練／專精是否能真正生效、裸能力是否吞掉適用拿手，以及 `文書／調查／追蹤／察覺／交涉／醫毒／格物` 等非正式 shorthand 是否被誤當角色卡拿手。

`社會名譽檢查.md` 是所有劇本共通的社會系統硬檢；它會檢查是否仍使用舊 `名望／聲譽／勢力關係／口碑` 數值、是否非法自創相對名譽對象、俠名／惡名／相對名譽倍率是否可直接結算，以及 NPC 是否真的因角色既有名譽改變主動透露、刻意隱瞞、准入、優勢／劣勢、修正值或下一步。

若最終劇本明列：
- `運行類別：可重覆任務`

則在三層共同檢查全部完成後，再完整讀取並執行：
- [`可重覆任務檢查.md`](可重覆任務檢查.md)

若最終劇本本身不是可重覆任務，但最終 md 宣告與一份可重覆任務有前置、後傳、承接、平行或其他跨劇本關連，則在共同檢查後，至少執行：
- [`可重覆任務檢查.md`](可重覆任務檢查.md) **第 9 節「跨劇本前置隔離硬檢」**。

若最終劇本含必要文字／讀音機關，再完整讀取並執行：
- [`文字機關檢查.md`](文字機關檢查.md)

所有劇本的共同檢查順序固定為：
1. `檢查.md`
2. `拿手檢查.md`
3. `社會名譽檢查.md`

若同時是可重覆任務與文字機關，完整五層檢查順序為：
1. `檢查.md`
2. `拿手檢查.md`
3. `社會名譽檢查.md`
4. `可重覆任務檢查.md`
5. `文字機關檢查.md`

其中 `可重覆任務檢查.md` 的姓名實例化項，對最終 md 已依 `文字機關設計.md` 明確證明為必要、且通過 `文字機關檢查.md` 的**最小固定欄位**不作失敗判定；其他 NPC／其他姓名欄仍按全可變要求驗收。

檢查階段負責：完成品／大綱判定、格式硬檢、反交付／反大綱閘門、拿手與非戰鬥判定硬檢、社會名譽硬檢、偏離覆檢及發布前驗收；可重覆任務另加驗事件可重現性、NPC／LOC／PROP／CLUE 實例化、實例識別、真相分支鎖定、重複獎勵上限及跨劇本前置隔離；文字機關另加驗世界內成因、字形／讀音實際可用性、普通話／粵語可達性及姓名最小固定合理性。

只要 `檢查.md`、`拿手檢查.md` 或 `社會名譽檢查.md` 任一硬性項目不通過，就必須回到劇本正文補完，再重新檢查；不得以「GM 到時自行補」「作者心裡知道」「理論上可有其他線索」「GM 會知道 shorthand 對應哪項拿手」「GM 自己按名聲調整」視為通過。

若屬「可重覆任務」，`可重覆任務檢查.md` 任一硬性項目不通過亦不得交付為該類別；只能回正文修正後重檢，或移除該類別並按一般 `once_per_character` 劇本處理。

若一般劇本與可重覆任務有跨劇本關連，而第 9 節前置隔離不通過，該關連關係亦不得交付；必須移除必要前置／handoff，或把來源事件改造成適合承接的非 repeatable 劇本。

若含必要文字／讀音機關，`文字機關檢查.md` 任一硬性項目不通過亦不得交付；不能把語音差異、粵語版本或姓名固定理由留給 GM 臨場補。

## 權威邊界

- **遊戲機制是甚麼**：`遊玩規則/`
- **可引用內容是甚麼**：`內容庫/`
- **正式相對名譽對象與 c 是甚麼**：`內容庫/相對名譽對象.md`
- **GM 如何運行**：`GM規則/`
- **GM 如何運行社會名譽**：`GM規則/社會互動.md`
- **一般劇本如何設計**：本目錄 `設計.md`
- **社會名譽如何設計**：本目錄 `社會名譽設計.md`
- **可重覆任務如何設計**：本目錄 `可重覆任務設計.md`（只在該類別加嚴適用；其跨劇本前置隔離條款亦適用於引用可重覆任務的其他劇本）
- **文字／讀音機關如何設計**：本目錄 `文字機關設計.md`
- **一般劇本是否合格可交付**：依序通過本目錄 `檢查.md`、`拿手檢查.md`、`社會名譽檢查.md`
- **拿手與非戰鬥判定是否合格**：本目錄 `拿手檢查.md`
- **社會名譽是否合格**：本目錄 `社會名譽檢查.md`
- **可重覆任務是否合格可交付**：先通過三層共同檢查，再通過 `可重覆任務檢查.md`
- **一般劇本引用可重覆任務是否合格**：在共同檢查後，另通過 `可重覆任務檢查.md` 第 9 節
- **文字／讀音機關是否合格**：另通過 `文字機關檢查.md`

同一規則不應在多個模組各自建立不同版本。若 `設計.md` 或類別補充規格要求某資料供 GM 使用，GM 的實際運行行為仍以 `GM規則/` 的權威主持流程為準。
