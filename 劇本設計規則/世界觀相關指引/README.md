# 世界觀相關指引

本目錄規範**已確立的世界設定如何轉化成可直接運行的劇本結構**。它不建立新的世界事實，也不取代 `世界知識庫/` 的權威條目。

## 讀取方式

由上層 [`../世界知識使用.md`](../世界知識使用.md) 路由進入本目錄後：

1. 所有正式劇本完整讀取 [`世界知識使用.md`](世界知識使用.md) 的共通正典使用規格。
2. 再依本劇本實際使用的世界結構讀取下列專項指引；沒有觸發的專項不必預載。

- [`組織與權力介入.md`](組織與權力介入.md)：劇本讓官署、王府、門派、商會、幫會或其他有層級的組織主動介入事件，尤其涉及高層／代理人、督辦、差遣、內部派系、命令衝突、權限升級或組織內不同立場時必讀。

## 權威分工

- **世界事實**：查 `世界知識庫/`；人物、組織、政治關係與既有制度以相應權威條目為準。
- **世界設定如何成為劇本事件**：依本目錄專項指引。
- **判定、戰鬥、名譽、資源等機械**：查 `遊玩規則/` 與 `內容庫/`。
- **GM 實際主持、載入、揭露與保存**：查 `GM規則/`。

本目錄只能規範劇本如何使用既有世界結構；若劇本需要改變共用世界事實，仍須依本目錄的 [`世界知識使用.md`](世界知識使用.md) 處理正典修訂或把變化限制在單一 `game_id`／戰役持續狀態內。
