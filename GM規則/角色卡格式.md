# GM規則：角色卡格式

本文件是《武與俠》玩家角色卡的權威格式。它規範角色卡須保存哪些目前狀態、成長資料與江湖履歷，以及各欄位之間必須維持的不變量。

- 建立新角色的程序見 `GM規則/創角.md`。
- 角色開始新劇本前的資格與合法性檢查見 `GM規則/開局檢查.md`；結算時的寫回、驗證與失敗復原見 `GM規則/結算.md`。
- 角色、戰鬥、武學與成長的機械數值仍以 `遊玩規則/` 為準；社會名譽的點數、級別與公式見 `遊玩規則/角色/社會名譽與門派.md`，正式相對名譽對象見 `內容庫/相對名譽對象.md`。

角色卡是**玩家可見的持久資料**。不得把未公開真相、NPC 隱藏身份、未發現線索或其他 GM 私密資訊寫入角色卡。

---

## 1. 角色卡的資料邊界

角色卡同時保存兩類資料：

1. **目前有效狀態**：角色現在的等級、歷練、武學、裝備、社會名譽、其他關係、長期傷患與其他會影響之後遊戲的資料。
2. **已結算歷史**：每次正式結算形成的江湖履歷及其目前有效 `receipt_version`。

普通短期戰鬥狀態、只在單一場景或劇本有效的危機鐘、臨時標記及已結束遭遇的數值，不得誤寫成角色永久特徵。若下一段採 `continuity_mode: continuous`，短期資源與狀態由同一 game save 或正式 `continuity_handoff` 承接；它們不因此變成角色卡的長期欄位。

角色卡保存角色**擁有甚麼、物品最近確認的存放位置，以及沒有進行中 `game_id` 時的最近／平常隨身配置**。一旦新局完成出發前整備，該 `game_id` 的 game save 成為本局「實際隨身／坐騎載物／留存」狀態的權威來源；遊戲中的取得、轉交、消耗、遺失或取回亦先寫入 game save，結算後才把仍需跨劇本保存的所有權與存放位置寫回角色卡。角色卡寫著「擁有」不代表物品在任何場景都自動隨身。

新角色使用同一格式，但江湖履歷明寫「無」。角色卡不得因換劇本、劇本建議等級不同或重新開團而重置；只有正式角色建立、遊戲事件、合法成長、版本化校正或結算寫回可以改變相應欄位。

## 2. 必填欄位

角色卡至少包含以下內容。

### 2.1 身份

- 姓名、等級、背景；
- 當前歷練池，以及升至下一級所需歷練；
- 門派／師承／武學來源；
- 江湖目標、信念、牽掛；
- 目前角色狀態，例如可投入遊戲、死亡、退休、失蹤、被俘或永久留置。

### 2.2 能力與熟練

- 力量、敏捷、體質、智力、直覺、魅力；
- 各能力修正值；
- 熟練加值；
- 4 項熟練拿手；
- 2 項擅長豁免；
- 專精（若有）。

### 2.3 衍生數值

- 氣血上限／目前氣血；
- 氣血骰總數／剩餘；
- AC、先攻、步速、被動察覺。

### 2.4 武學

- 每套已取得來源、正在修習或已掌握的武學：類別、各來源形式與具體來源、各來源傳承上限與是否有效／需持有、保留上限、可修上限、尚需前提、入門完成狀態與未完成修習段；
- 所有已掌握內功：名稱、主要／次要身分、內功主屬性、有效等級、功力、最高可用階數與已解鎖能力；
- 所有已掌握外功：名稱、實際外功等級、武學主屬性、武勢與已解鎖招式；
- 外功等級點：累積取得、逐套已投入、未分配餘額；
- 本次任務的主外功、次外功（若有）與次外功有效等級；
- 所有已掌握輕功：名稱、固定 18 點潛能分布或正式條目、有效等級與已解鎖階段，以及目前調用中的輕功；
- 其他已學非外功武學。

### 2.5 能力與裝備

- 背景利益；
- 絕活；
- 武器攻擊加值與傷害；
- 護具；
- 暗器、丹藥、毒藥、材料、工具與其他重要物品，均有實際數量；
- **攜帶格上限**，依 `遊玩規則/系統與機制/裝備基礎.md` 計算；
- 沒有進行中 `game_id` 時最近確認的**隨身配置、已用攜帶格**；若有坐騎／車輛，另記其載物及已用／上限承載格；
- 沒有隨身的已擁有物品之**留存位置**；位置可寫住處、客棧寄存、門派、共享資產保管處或其他已成立地點，不可只寫「倉庫」而沒有可重新取得的世界位置；
- 銀兩；
- 共有或暫時保管的資產（若有）。

物品所有權與實際可接觸狀態必須分開。角色卡可以保存「擁有但留在某地」的物品；這類物品在角色實際回到存放位置、有人送達或以其他世界內方式重新取得之前不能使用。

### 2.6 江湖狀態

角色卡必須保存：

- **俠名**：累積總點數、由公式推導的級別；
- **惡名**：累積總點數、由公式推導的級別；
- **名氣**：`俠名總點數 + 惡名總點數`，以及由公式推導的級別；名氣不得另有獨立點數來源；
- **相對名譽**：只列角色實際曾有非 0 變化、或劇情明確需要保存的正式對象；每項至少記對象正式名稱、淨點數與有號級別；
- 人情、恩義、仇怨、懸賞、債務、承諾等持續狀態；
- 長期狀態／特殊傷患（若有）。

新角色俠名、惡名、名氣均為 0.0；相對名譽沒有已發生變化時可寫「無（所有正式對象視為 0.0）」而不需要把整份登錄表逐項抄入角色卡。

**舊欄位 `名望／聲譽／勢力關係／口碑` 不再是現行角色卡數值。** 舊角色卡若仍有這些欄位，不得在沒有可稽核來源的情況下猜測換算；依正式遷移／校正程序處理。

### 2.7 成長狀態

- `pending_advancement`：尚未完成的必選升級事項；沒有時明寫「無」；
- 所有規則允許保留的未分配點數及其帳目；
- 最近一次相關結算憑證的 `game_id` 與目前有效 `receipt_version`（若有）。

### 2.8 江湖履歷

- 過往每次正式結算的玩家可見紀錄；
- 新角色明確記為「無」，不得虛構未曾參與的劇本經歷。

---

## 3. 成長狀態格式

每項 `pending_advancement` 至少記錄：

- 來源 `game_id` 及角色等級；
- 必須完成的選擇或擲骰；
- 目前狀態；
- 對哪些角色數值產生連動影響；
- 對應結算憑證的目前有效 `receipt_version`。

能力值提升／絕活、每級氣血增加方式／結果及其他規則明定必須選定的成長，屬於 `pending_advancement`。外功等規則明確允許保留的未分配點數不是待完成升級，必須另設點數帳，不得混在 `pending_advancement` 內。

每個可保留點數池至少記錄「累積取得、逐項已投入、未分配餘額」。外功等級點必須符合：

**逐套已投入總和 + 未分配 = 累積取得。**

未分配不得為負；已投入點數仍須符合學習資格、投入時點、解鎖條件及單套 20 級上限。合法未分配餘額可以保留，不要求為了完成角色卡而全部投入。

---

## 4. 江湖履歷格式

每次正式結算在每名實際參與 PC 的角色卡保留一筆履歷。每筆至少包含：

- **紀錄鍵**：本局唯一 `game_id`；
- **劇本**：`script_id`、劇本名稱及版本／來源；
- **重跑政策**：本局有效 `replay_policy`；若為 `repeatable`，另記本次適用的重複獎勵／後果上限；
- **結算類型**：完成結局、失敗結局、任務放棄或提前撤離；
- **實際結局**：`ending_id`、玩家可見結局名稱及重要變體；
- **時間**：結算日期；若有可靠的遊戲內日期亦一併記錄；
- **個人所得**：該角色最終實得的歷練 tag／點數及總數，即使為 0 亦明寫；
- **社會名譽增減**：本局俠名增加、惡名增加、由此造成的名氣變化，以及每個有變化的正式相對名譽對象；
- **持續後果摘要**：只列玩家已知、會跨劇本延續的社會名譽、人情／恩義／仇怨／懸賞／債務／承諾、物品、資格、傷患或角色最終狀態；
- **結算憑證**：目前有效 `receipt_version`。

同一角色卡內，每個 `game_id` 只能有一筆江湖履歷。寫回重試、結算校正或待選升級完成時，只能依正式版本流程更新該筆的有效資料，不得再次追加同一 `game_id`，也不得無痕覆寫或刪除過往紀錄。

江湖履歷必須能按 `script_id` 完整檢索，供開始新劇本前核對重跑資格。新的劇本版本、新的 `game_id`、先前失敗／放棄／提前撤離或取得 0 歷練，都不會令既有履歷失效。實際重跑資格由 `GM規則/開局檢查.md` 依當前劇本 `replay_policy` 判定。

若舊履歷沒有 `script_id` 或 `ending_id`，保留原始名稱、版本／來源與結局文字，不得猜測重寫。若舊履歷只有舊制名望／聲譽／勢力關係，亦保留原文並標記待遷移，不得靜默推導成新點數。用於重跑核對時依 `GM規則/開局檢查.md` 建立可稽核對應；用於結算校正時依 `GM規則/結算.md` 版本化處理。

## 5. 共有與暫管資產格式

每項共有或暫時保管的資產至少記錄：

- `shared_asset_id`；
- 項目及實際總量；
- 各角色的權利份額或共同權利人；
- 真正所有者（如屬借用／暫管）；
- 目前保管者／位置；
- 使用限制；
- 歸還、領取或分配條件。

同一共有項目出現在多張角色卡時，所有卡只引用同一 `shared_asset_id` 與同一實際總量，不得把總量或機械效果複製成每名角色各有一份。結算時仍未分配的項目可以保持共同持有，不得為了填滿角色卡而由 GM 強制分配。

---

## 6. 長期狀態欄位

角色卡必須保留「長期狀態／特殊傷患」欄；沒有時明寫「無」。劇本結束時如何判斷、記錄、更新或解除長期特殊傷患，以及該欄每項必須保存的資料，統一依 `GM規則/結算.md` 的「長期特殊傷患的角色卡紀錄」處理，本文件不重複結算程序。

## 8. 格式與內部一致性核對

建立或更新角色卡後確認：

- 所有第 2 節必填欄位存在；沒有內容的欄位明寫「無」，不以省略代表無；
- 等級、歷練池、下一級需求與熟練加值一致；
- 能力值、背景加值、修正值、氣血、氣血骰、AC、先攻、步速與被動察覺正確；
- 熟練拿手、豁免、內功功力／階數／能力、輕功 18 點分布均完整；
- 每套武學的各來源、傳承上限與有效／持有狀態、保留／可修上限、尚需前提、入門狀態及未完成修習段均完整且互相一致；
- 所有主要／次要內功及已掌握輕功均已列出，目前運行內功與調用輕功的狀態明確；
- 每套外功的實際等級、武勢、已解鎖招式及本次主／次外功資料正確；
- 各點數池的累積取得 = 已投入總和 + 未分配，且投入符合上限、資格與解鎖規則；
- `pending_advancement` 與可保留未分配點數分開記錄；
- 武器攻擊加值與傷害已算好，裝備、消耗品、材料與工具有數量；
- 攜帶格上限依力量修正值正確計算；最近確認隨身配置的已用格數可逐項重算且**不超過上限**；坐騎／車輛載物亦不超過其正式承載格；
- 所有已擁有但未隨身的物品都有可重新取得的存放位置，不以「角色擁有」冒充「目前可用」；有進行中 `game_id` 時，實際隨身／留存狀態以該局最新有效 game save 為準；
- 共有／暫管資產的 `shared_asset_id`、總量、權利及保管狀態在所有相關角色卡一致，沒有複製資產；
- 俠名／惡名總點數與級別符合 `c=2,k=4`；名氣總點數恰等於兩者相加且級別重新按公式推導，沒有獨立增減；
- 每個相對名譽對象都能在 `內容庫/相對名譽對象.md` 找到，點數與級別使用該對象正式 c；
- 沒有把 `名望／聲譽／勢力關係／口碑` 當成仍有效的新制數值；
- 人情、恩義、仇怨、懸賞、債務、承諾與角色狀態完整；長期特殊傷患符合 `GM規則/結算.md` 的紀錄規格；
- 每個 `game_id` 最多一筆江湖履歷，所有履歷均指向目前有效的 `receipt_version`，且沒有 GM 私密資訊；
- 每個特殊能力都能追溯到遊玩規則、內容庫或正式批准的自創條目。
