# GM遊戲流程：基本主持

> 劇本內循環入口與基本主持節奏；與本局存檔規則分拆以降低常駐上下文。

本文件只用於開始或續跑後的**劇本內循環**，直至凍結終局並交入結算。進入本文件前的 persistent storage 環境見 `GM規則/開局環境.md`，角色卡、重跑履歷與主持準備見 `GM規則/開局檢查.md`；角色建立見 `GM規則/創角.md`，角色卡欄位見 `GM規則/角色卡格式.md`，結算見 `GM規則/結算.md`。角色、戰鬥與武學機械以 `遊玩規則/` 為準；武學、毒藥、丹藥、裝備與敵人優先引用 `內容庫/`。

## 1. 劇本內循環範圍

本文件只在 `GM規則/開局檢查.md` 已完成角色資格、重跑履歷、待選升級、連續性與主持資料準備，且宿主／系統已建立或載入正確 `game_id` 後開始適用。它接收已核對的 PC 快照、當前劇本與本局存檔，不在劇本進行中重新創角、搜尋江湖履歷或改作入場資格判定。

本文件涵蓋劇本內的描述 → 玩家決策 → 可行性／判定 → 後果 → 世界推進循環，以及同一 `game_id` 的保存、暫停與續跑。當流程到達完成、失敗、任務放棄或提前撤離，只凍結最後有效狀態並交入 `GM規則/結算.md`；結算計算、角色卡寫回與存檔關閉不屬本文件。

## 2. 基本主持循環
GM的工作不是替玩家決定做法，而是維持一個有因果、會持續運作的江湖世界。

標準流程：
1. 描述當前環境、可見人物與明顯危險。
2. 問玩家「你要做什麼？」
3. 依第3.1節檢查玩家所述方法、角色能力與世界狀態；涉及正式能力或物件時先查閱內容庫／遊玩規則條目。不可能的結果直接否決，可能成立才判斷是否需要擲骰。
4. 若要判定，依第3.3節鎖定目標、方法、投入、協助及成本，並說明使用的能力／拿手、是否熟練、優劣勢、DC或對抗方式、成功範圍，以及角色可預見的主要風險。
5. 玩家自行擲骰並回報結果。
6. 按結果與世界狀態敘述後果。
7. 推進NPC、危機、時間與世界反應。

玩家描述「方法」很重要。好的方法可以令行動自動成功、降低風險、取得優勢、使用更合適的能力或避開判定；不應把所有創意都壓成同一顆骰。
