# 年表與關係

本文件提供跨劇本可共用的歷史先後與承泰二十一年組織關係。年表只固定大事件，不表示每名百姓都知道完整細節；人物知識仍取決於出身、拿手、消息來源與劇本情境。

## 1. 昊國與門派年表

| 時間 | 固定事件 |
|---|---|
| **昊曆前六十三年** | 渡厄禪師在慈航山整合護送難民的僧眾，禪林寺武脈成形。寺院本身比昊國更早存在。 |
| **昊曆前二十七年** | 張玄微在玄當山統合五峰道觀，玄當派成立。 |
| **昊曆元年** | 蕭定川結束諸鎮混戰，建立昊國、定都雍京，史稱太祖。 |
| **昊曆三十四年** | 石觀峰帶工匠、獵戶守住天嶽棧道，天嶽派立門。 |
| **昊曆四十八年** | 朔北三關潰亂；岳驚川守鳴雷關、赫連望維持崖路傳訊，風雷殿與飛鷲派先後成形。 |
| **昊曆七十一年** | 赤燼山礦火後，祝紅綾帶倖存工匠脫離礦主控制，建立赤煉宮。 |
| **昊曆八十三年** | 蘭辛夷在嶺南大疫中建立百草閣的採藥、記錄與外診制度。 |
| **昊曆九十一年** | 申屠渡因高風險戰傷療法被原醫門逐出，在無回峽建立黃泉谷；百草與黃泉的醫理爭論自此延續。 |
| **昊曆一百零五年** | 蘇絳帶江南戲班、織戶與護院脫離豪強控制，鳳羽宮立門。 |
| **昊曆一百一十七年** | 唐無窮拒交無刻印殺人機關，率工匠遷入千機峽，天機閣立門。 |
| **昊曆一百二十九年** | 東海寇亂後，顧千帆聯合退役軍士、船匠與漁戶在定潮島建立蒼龍門。 |
| **昊曆一百四十四年** | 聞人岫在雲門山聚徒，雲霧宗正式使用宗門名號。 |
| **昊曆一百五十二年** | 鏡湖大水後，冷月衣在寒汀湖建立霜華閣。 |
| **昊曆一百六十三年** | 晏無聲公布第一版血契規矩，血影門由鬆散受僱者變成有門規的組織。 |
| **昊曆一百七十一年** | 謝無涯揭穿引發地方屠殺的假信案，在照影城建立映真館，鏡影閣立門。 |
| **昊曆一百七十八年** | 杜百城在斷刃谷舉行第一次有見證、停手與復盤規矩的公開試刀，刀狂谷立門。 |
| **昊曆一百八十九年** | 十六派代表在照江簽成第一次「鏡湖公議」，承認彼此山門與調停席位；它不是永久武林政府。 |
| **昊曆二百零六年** | 東海大風災與海寇並發，蒼龍門、天機閣、四海船盟及東海水師共同重開主航道。 |
| **昊曆二百一十六年** | 史家顧西樓去世，《昊史別錄》開始在民間大量翻刻。 |
| **昊曆二百二十一年／承泰元年** | 蕭景衡平定京營兵變餘波後即位，改元承泰。 |
| **承泰三年** | 朝廷、地方代表與十六派多數山門重修「靖武約」，確立門派自治與刑律底線。血影門只透過代理人留下印記，未公開出席。 |
| **承泰八年** | 司徒照膽偵破紅燭連案，武學痕跡不得單獨定罪成為刑部公開辦案慣例。 |
| **承泰十五年** | 朔北三關戰事擴大，風雷殿、飛鷲派與鎮北軍共同守住白狼川；各方對功勞與軍糧仍有爭議。 |
| **承泰十八年** | 寒潭叟白蘸雪離開鏡湖，此後下落不明。 |
| **承泰十九年** | 照江舉行鏡湖論武，公孫止戈主持停手規則；路非狂連敗兩場後又勝三場而成名。 |
| **承泰二十一年** | Handbook 基準時點。通京大渠待修、太子推動靖武約成文化、朔北軍費高企，十六派首領與主要人物以各文件所列狀態在世或已故。 |

## 2. 十六派當前主要關係

以下是組織層級的公開基準，不是每名門人的自動私人態度，也不取代角色相對名譽。

| 雙方 | 基準關係 | 核心原因 |
|---|---|---|
| 禪林寺—玄當派 | 互敬、常共同調停 | 都重克制與養生，但禪林較重戒律，玄當較重權衡。 |
| 禪林寺—黃泉谷 | 理念衝突、保留合作 | 禪林反對吸功與高風險療法；疑難重傷時仍可能求助。 |
| 玄當派—天嶽派 | 穩定合作 | 共同保存天風步法不同註解，也維護京畿至河洛山路。 |
| 赤煉宮—百草閣 | 交易兼論爭 | 共享礦毒、火傷與解毒資料，對試毒界線意見不同。 |
| 赤煉宮—風雷殿 | 西北互助、爭功 | 共護西路，常為商隊與軍鎮委託誰負責而競爭。 |
| 霜華閣—鳳羽宮 | 友好競爭 | 劍、刀與身法交流頻繁，兩派都重視庇護與門人自立。 |
| 霜華閣—鏡影閣 | 有限合作、互不全信 | 共同處理鏡湖消息，對易容與情報手段界線不同。 |
| 風雷殿—飛鷲派 | 守邊同盟、同輩較勁 | 一方偏軍陣守關，一方偏山地傳訊與邊民自主。 |
| 血影門—鏡影閣 | 長期敵對競爭 | 爭奪身份、情報與委託來源；鏡影常揭穿血契證據，血影也滲透其渠道。 |
| 雲霧宗—鏡影閣 | 思想相近、方法互防 | 都重多角度觀察；雲霧宗不接受鏡影閣為求證而操控局勢。 |
| 百草閣—黃泉谷 | 根本分歧、災時合作 | 對高風險療法、屍理解剖與吸功代價看法不同；大疫時曾共享病例。 |
| 鳳羽宮—雲錦行 | 長期合作、互不隸屬 | 工坊、戲服與避難安置互相支援；商號不能命令山門。 |
| 天機閣—蒼龍門 | 技術盟友 | 合作船械、水工與救難設備，仍分別保留核心圖譜與門規。 |
| 飛鷲派—千里駝行 | 商路合作 | 互通井堡與護送消息；飛鷲派拒為違禁私運背書。 |
| 刀狂谷—蒼龍門 | 尊重、定期試鋒 | 重刀與槍戟互相驗證，雙方都看重公開規矩與停手。 |
| 刀狂谷—血影門 | 理念不合 | 刀狂谷認為無見證偷襲不能證明刀道；血影門認為活著完成契約才是結果。 |

## 3. 朝廷與門派的接觸線

| 對象 | 最常接觸的朝廷系統 | 基準狀態 |
|---|---|---|
| 禪林寺、玄當派 | 禮部、地方府縣、靖武司 | 常被邀調停；不等於替朝廷背書。 |
| 風雷殿、飛鷲派 | 樞密院、鎮北軍 | 守邊合作最深，也最容易因軍令與地方自主起衝突。 |
| 蒼龍門、天機閣 | 水師、工部相關衙署、靖武司 | 以船械、水工與救難合作；核心技術與指揮權常有爭議。 |
| 百草閣、黃泉谷、赤煉宮 | 地方醫署、刑部、軍鎮 | 疫病、毒案與戰傷時被倚重；毒方與高風險療法受監察。 |
| 血影門、鏡影閣 | 刑部、靖武司 | 前者被重點追查，後者有時提供情報但不具官府搜捕權。 |
| 其餘門派 | 地方府縣、禮部、靖武司 | 依山門土地、公開比武、護路與地方案件接觸。 |

## 4. 公共事件與局部歷史

劇本可新增不改變上述骨架的地方舊案、災難、比武、婚盟、支派分裂與人物恩怨。若新增事件聲稱：

- 改變昊國立國年份或當朝年號；
- 令十六派之一在基準時點前已滅門、易主或遷離固定山門；
- 把已故人物改成仍在世；
- 讓已固定武學由另一人創立；
- 讓兩道、大河或主要山脈的相對位置改變；

便不是普通地方補充，應先修訂 Handbook 或明確標成非正典／該桌分歧時間線。

## 5. 對人物知識的建議尺度

- **普通民間**：多知道皇帝、首都、所在道、大城、附近山門及最響亮外號，細節常混有說書傳聞。
- **商旅／鏢行**：較熟道路、商號、山寨、關城、船盟與跨地區近況。
- **官府人物**：按職務知道正式官銜、通緝與公文；不自動知道門派秘傳。
- **武林人士**：較熟十六派首領、代表武學、論武與舊怨；不自動知道神秘人物真名或朝廷密議。
- **專門研究者**：可透過學問、拿手、檔案、人脈與劇本線索得到更精確內容。世界知識庫是 GM／作者的世界基準，不表示每名 PC 開局全知。
