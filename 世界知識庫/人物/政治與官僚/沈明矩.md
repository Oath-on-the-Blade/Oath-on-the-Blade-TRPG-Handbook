# 沈明矩

- **官職**：公保；外號「直衡公」。
- **年齡**：六十一歲。
- **出身**：寒門進士，早年長期任刑獄與地方按察職。
- **政治取向**：最重公開規則、程序一致與可覆核的官府權力；認為朝廷若要求百姓守法，首先必須讓百姓知道法是甚麼。是沈系／法理一系最高朝堂支點。
- **用人網絡**：門下在御史、刑名、文書與地方按察職中最活躍，常提拔能把原則寫成可查核條文的人。
- **院社關係**：[明理院](../../組織/政治與官僚/明理院.md)主動擁戴他為理念典範；他不是院方上級。他會閱讀院方整理的錯案資料，但也反對把未經查證的傳聞先當成「民意公議」。
- **儲位立場**：支持現有太子，並主張任何廢立都必須提出可公開辯護的重大理由與正式程序。
