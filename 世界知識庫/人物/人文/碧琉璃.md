# 碧琉璃

- **身份**：綺雲樓名伶；「碧琉璃」是柳如意替她改取的藝名，本名少有人知；承泰二十一年最受議論的風月名人之一。
- **年齡**：二十四歲。
- **外貌**：碧眼，容貌與髮色明顯帶有昊國之外的血統特徵。
- **來歷**：生於昊國之外，年少時遭跨境人口販子拐賣至西海，抵達昊國後獲人救出並收留數年；後被救命恩人身邊人出賣至青樓。柳如意將她買下後帶入綺雲樓，安排識字、學語與歌舞訓練；她再憑自己的音感、記性、談吐與異地見聞逐步成為名伶。其故國與原有家世在昊國少有可靠記錄。
- **名聲**：以歌舞、談吐與異地見聞聞名，常成為商旅、文人與富戶席間議論人物。
- **所屬**：[綺雲樓](../../組織/商業/商會/旗下事業/綺雲樓.md)。
