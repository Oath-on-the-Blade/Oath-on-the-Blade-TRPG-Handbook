# 當前江湖關係

以下只保存承泰二十一年的公開關係網；各組織自身細節仍以實體權威檔為準。

| 雙方 | 公開關係 | 核心原因 |
|---|---|---|
| 禪林寺—玄當派 | 互敬、常共同調停 | 都重克制與養生。 |
| 禪林寺—黃泉谷 | 理念衝突、保留合作 | 高風險療法與救命需要並存。 |
| 玄當派—天嶽派 | 穩定合作 | 共同保存天風步法不同註解並維護山路。 |
| 赤煉宮—百草閣 | 交易兼論爭 | 礦毒、火傷與試毒界線。 |
| 赤煉宮—風雷殿 | 東北互助、爭功 | 共護東方商路與軍鎮委託。 |
| 霜華閣—鳳羽宮 | 友好競爭 | 劍、刀與身法交流頻繁。 |
| 霜華閣—鏡影閣 | 有限合作、互不全信 | 對情報與易容手段界線不同。 |
| 風雷殿—飛鷲派 | 守邊同盟、同輩較勁 | 軍陣守關與山地傳訊互補。 |
| 血影門—鏡影閣 | 長期敵對競爭 | 爭奪身份、情報與委託來源。 |
| 雲霧宗—鏡影閣 | 思想相近、方法互防 | 都重多角度觀察。 |
| 百草閣—黃泉谷 | 根本分歧、災時合作 | 高風險療法與死亡記錄。 |
| 天機閣—蒼龍門 | 技術盟友 | 船械、水工與救難設備合作。 |
| 刀狂谷—蒼龍門 | 尊重、定期試鋒 | 重武學驗證與公開規矩。 |
| 刀狂谷—血影門 | 理念不合 | 正式試刀與偷襲契約的價值觀衝突。 |

## 朝廷接觸線

邊地門派常接觸樞密院與軍鎮；醫毒門派常接觸地方醫署、刑部與軍鎮；血影門與鏡影閣常被刑部、靖武司關注；其他門派依山門土地、護路與案件主要接觸地方府縣、禮制官員與靖武司。
