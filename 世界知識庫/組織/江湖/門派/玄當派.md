# 玄當派

- **山門**：京畿道玄當山。
- **開山祖師**：[張玄微](../../../人物/江湖/張玄微.md)。
- **理念**：「不爭一息，爭全局之衡。」重借力、觀勢、養生與克制，不等於永遠中立。
- **組織**：掌教主持；玄當五峰各由真人主持；玄當七子是當代七名最受矚目後進，席位隨退隱、逐出或新選更替。
- **現任掌教**：[陸觀潮](../../../人物/江湖/陸觀潮.md)。
- **著名高層**：[白松年](../../../人物/江湖/白松年.md)，五峰真人之一。
- **著名後進**：[沈太和](../../../人物/江湖/沈太和.md)，玄當七子之首。
- **代表傳承**：玄當內氣法、雲海太極拳、太極十三槍、玄門游龍槍、太虛劍訣、天風步法。
- **當前關係**：與天嶽派共同保存天風步法不同註解；與朝廷往來頻繁，也因此常被其他門派懷疑過於親官。
