# 雲霧宗

- **山門**：巴蜀道雲門山。
- **開山祖師**：[聞人岫](../../../人物/江湖/聞人岫.md)。
- **理念**：「形可變，守心不變。」重觀察、留白、退路與多角度理解。
- **組織**：宗主主持；雲臺六隱各守一門學問或武學；雲門五鶴是可代表宗門出行的後進。
- **現任宗主**：[蘇停雲](../../../人物/江湖/蘇停雲.md)。
- **著名高層**：[章不語](../../../人物/江湖/章不語.md)，六隱之一。
- **著名後進**：[白含煙](../../../人物/江湖/白含煙.md)。
- **代表傳承**：太虛氣功、雲霧劍法、天霧劍氣、雲中漫步。
- **當前關係**：與鏡影閣互換情報又互防誤導；在百草閣與黃泉谷醫理爭端中常充當傳話者。
