# 風雷殿

- **山門**：朔北道鳴雷關外堡。
- **開山祖師**：[岳驚川](../../../人物/江湖/岳驚川.md)。
- **理念**：「先至、先斷、先護住缺口。」崇尚迅速決斷，但門規要求先辨真正威脅，不能把魯莽當豪氣。
- **組織**：殿主之下有風雷五將，分掌槍、刀、暗器、騎行與守關；驚蟄三英是當代三名最著名年輕門人。
- **現任殿主**：[韓千霆](../../../人物/江湖/韓千霆.md)。
- **著名高層**：[宋斷岳](../../../人物/江湖/宋斷岳.md)主持合擊與守城訓練。
- **著名後進**：[霍青電](../../../人物/江湖/霍青電.md)，驚蟄三英之一。
- **代表傳承**：烈陽神功、風雷破陣槍、迅雷連環槍、鳴雷刀訣、破風刀訣、穿空石。
- **當前關係**：與飛鷲派共同守邊但常爭功；與朝廷軍鎮合作密切，門內因此存在「守國」與「守民不等於聽官」兩派聲音。
