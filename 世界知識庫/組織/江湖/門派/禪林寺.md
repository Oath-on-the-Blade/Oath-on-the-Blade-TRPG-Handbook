# 禪林寺

- **山門**：河洛道慈航山。
- **開山祖師**：[渡厄禪師](../../../人物/江湖/渡厄禪師.md)。
- **理念**：「拳為止暴，力先自制。」寺中重戒殺，但戒殺不等於見死不救；護人、制伏與承擔後果高於求勝。
- **組織**：方丈總理寺務；禪、律、武、知客四院各有首座；八行僧是跨院選出的年輕行腳僧，不是八人共同掌權。
- **現任方丈**：[寂照方丈](../../../人物/江湖/寂照方丈.md)。
- **著名高層**：[行嚴](../../../人物/江湖/行嚴.md)任武院首座。
- **著名後進**：[明塵](../../../人物/江湖/明塵.md)，八行僧之一。
- **代表傳承**：金剛護體功、羅漢神拳、普渡棍法、金剛鎮山棍、慈航步法。
- **當前關係**：與玄當派長期互敬；對黃泉谷的吸功與屍理解剖極不認同，但仍承認其救治疑難傷患的能力。
