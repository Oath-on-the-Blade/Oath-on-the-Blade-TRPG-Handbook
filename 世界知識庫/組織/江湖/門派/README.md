# 門派索引

承泰二十一年，目前在江湖中較具影響力的門派如下。這不是朝廷封定的唯一門派名冊；各地另有地方山門、武館、寺觀、家傳武脈與新興組織。

| 門派 | 首領正式稱呼 | 高層特稱 | 著名後進特稱 |
|---|---|---|---|
| [禪林寺](禪林寺.md) | 方丈 | 四院首座 | 八行僧 |
| [玄當派](玄當派.md) | 掌教 | 五峰真人 | 玄當七子 |
| [赤煉宮](赤煉宮.md) | 宮主 | 三爐主 | 五火使 |
| [霜華閣](霜華閣.md) | 閣主 | 四雪使 | 霜華六秀 |
| [風雷殿](風雷殿.md) | 殿主 | 風雷五將 | 驚蟄三英 |
| [天嶽派](天嶽派.md) | 嶽主 | 六峰座 | 天嶽雙璧 |
| [血影門](血影門.md) | 門主 | 四影 | 七血衣 |
| [雲霧宗](雲霧宗.md) | 宗主 | 雲臺六隱 | 雲門五鶴 |
| [百草閣](百草閣.md) | 大藥主 | 四時藥正 | 百草十青 |
| [黃泉谷](黃泉谷.md) | 谷主 | 六渡使 | 黃泉三客 |
| [鳳羽宮](鳳羽宮.md) | 宮主 | 七翎座 | 五色翎 |
| [天機閣](天機閣.md) | 閣主 | 天機七匠 | 九巧徒 |
| [飛鷲派](飛鷲派.md) | 鷲首 | 四翼尊 | 十三翎 |
| [刀狂谷](刀狂谷.md) | 刀魁 | 五刀侯 | 九試刀徒 |
| [蒼龍門](蒼龍門.md) | 龍首 | 五鎮 | 八小龍 |
| [鏡影閣](鏡影閣.md) | 鏡主 | 七面使 | 十二影徒 |

江湖外人常泛稱各派首領為「掌門」，正式往來仍使用各派自身稱呼。
