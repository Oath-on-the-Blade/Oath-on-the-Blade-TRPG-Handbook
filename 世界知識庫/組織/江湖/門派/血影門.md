# 血影門

- **山門**：無公開固定總壇；各道城市有獨立影房與聯絡人，門人亦會以商旅身份與臨時聯絡處活動。承泰二十一年沒有可靠來源能證明存在一處「血影門唯一總壇」。
- **開山祖師**：[晏無聲](../../../人物/江湖/晏無聲.md)。
- **理念**：「情報先於刀，代價先於命。」血影門仍是受僱殺人與秘密行動的門派，不因有規矩便成正派；門內也常有人違約爭權。
- **組織**：門主透過四影統理各道影房；七血衣是能獨立承接高風險任務的年輕骨幹。四影只以色與代號出席，真名不對外公開。
- **現任門主**：[戚夜白](../../../人物/江湖/戚夜白.md)。
- **著名高層**：[白影](../../../人物/江湖/白影.md)，四影之一。
- **著名後進**：[殷小滿](../../../人物/江湖/殷小滿.md)，七血衣之一。
- **代表傳承**：噬魂毒掌、無影刺殺術、血影飛刀、奪命影步。
- **當前關係**：與鏡影閣爭奪情報來源；朝廷把血影門列為重點監察對象，但沒有證據證明每宗暗殺都出自該門。
