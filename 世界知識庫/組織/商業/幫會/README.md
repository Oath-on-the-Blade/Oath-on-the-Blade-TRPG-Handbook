# 幫會索引

承泰二十一年已有十三個幫會具備跨城、跨道經營或快速擴張規模。長河幫、黑牙幫、無常會因總體規模、資金與地下信用最廣，被俗稱「三大幫會」；這只是規模稱呼，不是上級關係。
