# 明理院

- **類型**：民間士人議政組織，不是朝廷正式書院，也沒有科舉、授官或司法權。
- **總院**：洛安；雍京、照江、澄州有固定講舍。
- **組成**：年輕舉子、落第士人、書吏、私塾先生、少量低階官員與律學研究者；三院社中最能吸引沒有官身與顯赫家世的民間文士。院友入仕後不會自動退出原來的院社。
- **主張**：法條應公開可查，刑罰與官權應有清楚邊界；反對只因身份、門第或官位不同便使用不同程序。主張減少口供定罪、限制刑訊、地方判決留下可覆核文書、靖武約條文化，也較願意談論官府對百姓應負的責任。
- **方法**：抄印小冊、公開講論、旁聽公開審理、整理錯案、聯署、替無力請訟師者寫狀紙。
- **院正**：[程照白](../../人物/政治與官僚/程照白.md)。
- **擁戴的朝中典範**：[沈明矩](../../人物/政治與官僚/沈明矩.md)。院內常抄錄他的判詞、奏議與反對濫刑的發言，把他視為「法理可以進入實政」的證明；沈明矩本人並不承認明理院是自己的外圍組織。
- **社會基礎**：在民間讀書人、寒門舉子、書吏與年輕士人中聲望最高。
- **爭議**：支持者稱其讓百姓知道規矩；批評者認為它鼓勵沒有行政責任的人用抽象原則攻擊所有妥協，或把書齋理想當成天下都能立即施行的規矩。
