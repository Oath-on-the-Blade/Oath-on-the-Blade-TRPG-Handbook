# 明理院

- **類型**：民間士人議政組織，不是朝廷正式書院。
- **總院**：洛安；雍京、照江、澄州有固定講舍。
- **組成**：年輕舉子、落第士人、書吏、私塾先生、少量低階官員與律學研究者；三院社中最能吸引沒有官身與顯赫家世的民間文士。
- **主張**：法條公開可查、程序一致、限制刑訊與官權任意、判決可覆核、靖武約條文化。
- **方法**：抄印、公開講論、整理錯案、聯署、旁聽公開審理、代寫狀紙。
- **院正**：[程照白](../../人物/政治與官僚/程照白.md)。
- **擁戴的朝中典範**：[沈明矩](../../人物/政治與官僚/沈明矩.md)。這是由下而上的理念擁戴，不是上下級。
- **社會基礎**：民間讀書人、寒門舉子、書吏與年輕士人。
