# 十道地方官府

> **Note｜索引與權威**
> - 十道名稱、邊界與治所以地理基準為準；本層索引各道官府作為地方行政與監察體系的制度實體。
> - 府、州、縣是各道之下的現行行政層級，但本索引不固定全國府州縣與地方官員的完整名冊。

各道官府是昊國地方行政與監察體系在該道的制度共同體，不是彼此獨立的國家。十道構成承泰二十一年的現行行政大區，各道之下另設府、州、縣。
