# 昊國地理

## 1. 國土與行政

昊國東臨滄海，西抵天脊山脈與長風沙海，北接朔原，南至萬藥嶺外緣。中央以**道**作監察與調度大區，道下設府、州、縣；邊境另有軍鎮與關城。道不是各自為政的封國，道治所在只代表該區行政與交通中樞。

雍京位於北中部。昊江由西向東貫穿巴蜀、荊湖與東海，澄河北上接近京畿；通京大渠把兩條水系連成朝廷的糧運命脈。

血影門沒有獲公開承認的固定總壇；其門人以城市據點、商旅身份與臨時聯絡處活動。承泰二十一年沒有可靠來源能證明存在一處可被稱為「血影門唯一總壇」的固定地點。

## 3. 首都與著名城市

### 雍京

昊國首都，外城沿澄河與通京大渠伸展，內有皇城「承天城」。城中最重要的區域包括六部官署集中的宣政坊、票號與大商行所在的金梁市、外地人聚集的南驛，以及受靖武司嚴密注視的西兵器街。雍京可佩常見兵器，但進承天城、官署與國倉須解兵驗牒。

### 洛安

南北官道與西關商路交會的大城，被稱為「天下腹心」。糧行、鏢局、馬市與武館林立；禪林寺及天嶽派都在一至數日路程內，因而也是門派調停與公開比武的常見地點。

### 鎮朔

北境三關的後方總城。軍戶、馬商、草原部族與飛鷲派門人混居，風雷殿常替軍鎮訓練斥候。冬季封路時，城價與消息都會劇烈波動。

### 赤關

西陲商隊入昊後第一座大城。駝行、礦商、鹽商與翻譯聚集；赤煉宮採買礦藥與燃料多經此地。城外九折關是合法商路、私運小徑與山賊勢力交疊之處。

### 錦川

巴蜀盆地中心，以紙、茶、漆器與書坊著名。雲門山常年霧重，無回峽則因險路、瘴氣與黃泉谷的名聲令外人卻步。

### 照江

鏡湖北岸大城，也是跨門派公議、論武與水運交易最常選用的中立城市。城西的照影城原是獨立小城，現與照江連成長市；鏡影閣在其中有公開館舍，但真正內院不對外開放。

### 澄州

江南道治所，絲織、書院、戲班與園林聞名。鳳羽宮在城南棲凰山設有接待外客的羽門別院；富商與文人往來令消息、流言與時尚傳得特別快。

### 海陵

昊國最大海港，設水師、海關、鹽運與造船場。蒼龍門在近海定潮島立門，既協助救難與護航，也時常與海關、船盟爭論誰有權處置可疑船隻。

### 南梧

嶺南藥材集散地。各地醫者、毒師與商人都會來此辨貨；百草閣在城內設公開藥院，但萬藥嶺山門只接待有引介或真正求醫者。

### 雲州

高原湖畔城市，以精密器具、水車、礦石與刀市聞名。天機閣的工匠與刀狂谷的試刀人令城中形成嚴格的兵器刻印、保管與公開試鋒規矩。

## 4. 著名山川湖海

| 名稱 | 類型 | 固定位置與特徵 |
|---|---|---|
| **昊江** | 大河 | 發源天脊山脈，經巴蜀、荊湖入東海；上游峽急，中游通航，東段潮汐明顯。 |
| **澄河** | 大河 | 自河洛北流入京畿，與通京大渠共同負擔漕糧。 |
| **鏡湖** | 湖泊 | 荊湖道中心、昊國最大淡水湖；島洲、蘆澤與深水航道並存。 |
| **寒汀湖** | 高地湖 | 鏡湖南緣山地的冷水湖，霜華閣建於湖畔石臺。冬季薄冰危險，不會整湖凍實。 |
| **蒼龍灣** | 海灣 | 東海道近海大灣，礁島密集；定潮島扼主航道。 |
| **天脊山脈** | 山脈 | 昊國西界長山系，千機峽、斷刃谷及多條西南商道皆在其支脈。 |
| **天嶽七峰** | 山群 | 河洛南部七座相連高峰；瀑布、棧橋與陡壁構成天嶽派山門。 |
| **玄當山** | 山地 | 京畿西緣道觀群與松林山路，靠近京畿但保有寺觀自治傳統。 |
| **萬藥嶺** | 山嶺 | 嶺南北部濕熱群山，藥草豐富，也有瘴地、毒蟲與易迷路的相似谷口。 |
| **長風沙海** | 沙漠／戈壁 | 隴右以西廣闊旱地；商路依井堡與星象連接，離路遠行極危險。 |
| **白狼川** | 草原河谷 | 朔北馬場與冬營地帶，亦是邊軍、牧民與山寨勢力常爭奪的通道。 |
