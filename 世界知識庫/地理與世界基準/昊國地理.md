# 昊國地理

## 國土與行政

昊國**西臨滄海，東抵天脊山脈與長風沙海，北接朔原，南至萬藥嶺外緣**。中央以**道**作監察與調度大區，道下設府、州、縣；邊境另有軍鎮與關城。道不是各自為政的封國，道治所只代表該區行政與交通中樞。

雍京位於北中部。昊江發源於東方天脊山脈，自東向西經巴蜀、荊湖流入西海；澄河北上接近京畿，通京大渠把主要水系連成朝廷糧運命脈。

## 首都與著名城市

### 雍京
昊國首都，外城沿澄河與通京大渠伸展，內有皇城「承天城」。宣政坊集中六部官署，金梁市聚集票號與大商行，南驛聚集外地旅人。進承天城、官署與國倉須解兵驗牒。

### 洛安
南北官道與東關商路交會的大城，被稱為「天下腹心」。糧行、鏢局、馬市與武館林立。

### 鎮朔
北境三關後方總城。軍戶、馬商、草原部族與武林人士混居，冬季封路時城價與消息波動劇烈。

### 赤關
東陲商隊入昊後第一座大城。駝行、礦商、鹽商與翻譯聚集；城外九折關是合法商路、私運小徑與山賊勢力交疊之處。

### 錦川
巴蜀盆地中心，以紙、茶、漆器與書坊著名。

### 照江
鏡湖北岸大城，也是跨門派公議、論武與水運交易常用的中立城市。

### 澄州
江南道治所，絲織、書院、戲班與園林聞名。

### 海陵
昊國最大西海港，設水師、海關、鹽運與造船場；外國商船亦可能在依法查驗後入港。具體外來往來見人文層。

### 南梧
嶺南藥材集散地，各地醫者、毒師與商人來此辨貨。

### 雲州
東方高原湖畔城市，以精密器具、水車、礦石與刀市聞名。

## 著名山川湖海

| 名稱 | 類型 | 固定位置與特徵 |
|---|---|---|
| **昊江** | 大河 | 發源東方天脊山脈，經巴蜀、荊湖向西入海；上游峽急，中游通航，西段潮汐明顯。 |
| **澄河** | 大河 | 自河洛北流入京畿，與通京大渠共同負擔漕糧。 |
| **鏡湖** | 湖泊 | 荊湖道中心、昊國最大淡水湖。 |
| **寒汀湖** | 高地湖 | 鏡湖南緣山地冷水湖。 |
| **蒼龍灣** | 海灣 | 西海道近海大灣，礁島密集；定潮島扼主航道。 |
| **天脊山脈** | 山脈 | 昊國東界長山系，千機峽、斷刃谷及多條東南商道在其支脈。 |
| **天嶽七峰** | 山群 | 河洛南部七座相連高峰。 |
| **玄當山** | 山地 | 京畿西緣道觀群與松林山路。 |
| **萬藥嶺** | 山嶺 | 嶺南北部濕熱群山。 |
| **長風沙海** | 沙漠／戈壁 | 隴東以東廣闊旱地；商路依井堡與星象連接，離路遠行極危險。 |
| **白狼川** | 草原河谷 | 朔北馬場與冬營地帶。 |
