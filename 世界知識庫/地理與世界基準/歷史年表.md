# 歷史年表

本檔只固定事件先後。具名人物與組織的完整資料由 `人物/`、`組織/` 權威檔保存。

| 時間 | 事件 |
|---|---|
| **昊曆前六十三年** | 渡厄禪師在慈航山整合護送難民的僧眾，禪林寺武脈成形。 |
| **昊曆前二十七年** | 張玄微在玄當山統合五峰道觀，玄當派成立。 |
| **昊曆元年** | 蕭定川結束諸鎮混戰，建立昊國、定都雍京。 |
| **昊曆三十四年** | 石觀峰帶工匠、獵戶守住天嶽棧道，天嶽派立門。 |
| **昊曆四十八年** | 朔北三關潰亂；岳驚川守鳴雷關、赫連望維持崖路傳訊，風雷殿與飛鷲派先後成形。 |
| **昊曆七十一年** | 赤燼山礦火後，祝紅綾帶倖存工匠脫離礦主控制，建立赤煉宮。 |
| **昊曆八十三年** | 蘭辛夷在嶺南大疫中建立百草閣的採藥、記錄與外診制度。 |
| **昊曆九十一年** | 申屠渡在無回峽建立黃泉谷。 |
| **昊曆一百零五年** | 蘇絳帶江南戲班、織戶與護院脫離豪強控制，鳳羽宮立門。 |
| **昊曆一百一十七年** | 唐無窮率工匠遷入千機峽，天機閣立門。 |
| **昊曆一百二十九年** | 西海寇亂後，顧千帆聯合退役軍士、船匠與漁戶在定潮島建立蒼龍門。 |
| **昊曆一百四十四年** | 聞人岫在雲門山聚徒，雲霧宗正式使用宗門名號。 |
| **昊曆一百五十二年** | 鏡湖大水後，冷月衣在寒汀湖建立霜華閣。 |
| **昊曆一百六十三年** | 晏無聲公布第一版血契規矩，血影門由鬆散受僱者變成有門規的組織。 |
| **昊曆一百七十一年** | 謝無涯揭穿引發地方屠殺的假信案，在照影城建立映真館，鏡影閣立門。 |
| **昊曆一百七十八年** | 杜百城在斷刃谷舉行第一次有見證、停手與復盤規矩的公開試刀，刀狂谷立門。 |
| **昊曆一百八十九年** | 當時十六個主要山門代表在照江簽成第一次「鏡湖公議」；十六個簽署方不等於天下只有十六個門派。 |
| **昊曆二百零六年** | 西海大風災與海寇並發，蒼龍門、天機閣、四海商會旗下船盟及西海水師共同重開主航道。 |
| **昊曆二百二十一年／承泰元年** | 蕭景衡平定京營兵變餘波後即位，改元承泰。 |
| **承泰三年** | 朝廷、地方代表與鏡湖公議主要簽署山門重修「靖武約」。 |
| **承泰八年** | 司徒照膽偵破紅燭連案，「武學痕跡不得單獨定罪」成為刑部公開辦案慣例。 |
| **承泰十五年** | 朔北三關戰事擴大，風雷殿、飛鷲派與鎮北軍共同守住白狼川。 |
| **承泰十八年** | 寒潭叟白蘸雪離開鏡湖，此後下落不明。 |
| **承泰十九年** | 照江舉行鏡湖論武，公孫止戈主持停手規則；路非狂由此成名。 |
| **承泰二十一年** | 通京大渠數段待修、太子推動靖武約成文化、朔北軍費高企；各大組織維持競合局面。 |
