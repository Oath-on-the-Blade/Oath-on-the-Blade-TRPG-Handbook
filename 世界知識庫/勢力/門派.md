# 門派

承泰二十一年，目前在江湖中較具影響力的門派如下。它們都有自己的山門、祖師、理念、組織稱呼、當代首領與代表傳承；「代表傳承」表示該派以此聞名，不代表每名弟子都掌握全部內容，也不表示所有招式都對外公開。

這不是朝廷封定的唯一門派名冊。各地另有地方山門、武館、寺觀、家傳武脈與新興組織；是否被視為大門派，通常取決於聲望、山門規模、傳承、公共往來與江湖承認，而非固定席位總數。

| 玄當派 | 掌教 | 五峰真人 | 玄當七子 |
| 赤煉宮 | 宮主 | 三爐主 | 五火使 |
| 霜華閣 | 閣主 | 四雪使 | 霜華六秀 |
| 風雷殿 | 殿主 | 風雷五將 | 驚蟄三英 |
| 天嶽派 | 嶽主 | 六峰座 | 天嶽雙璧 |
| 血影門 | 門主 | 四影 | 七血衣 |
| 雲霧宗 | 宗主 | 雲臺六隱 | 雲門五鶴 |
| 百草閣 | 大藥主 | 四時藥正 | 百草十青 |
| 黃泉谷 | 谷主 | 六渡使 | 黃泉三客 |
| 鳳羽宮 | 宮主 | 七翎座 | 五色翎 |
| 天機閣 | 閣主 | 天機七匠 | 九巧徒 |
| 飛鷲派 | 鷲首 | 四翼尊 | 十三翎 |
| 刀狂谷 | 刀魁 | 五刀侯 | 九試刀徒 |
| 蒼龍門 | 龍首 | 五鎮 | 八小龍 |
| 鏡影閣 | 鏡主 | 七面使 | 十二影徒 |

江湖外人常把各派首領泛稱為「掌門」，但門內與正式往來仍使用各自稱呼，例如玄當派稱掌教、禪林寺稱方丈。
