# 商賈、文壇與百業

江湖不只由門派與官府構成。票號能決定一批糧幾時到，船盟能令消息沿昊江流動，文人的文章能把一次地方衝突變成天下議論。以下人物與事業是承泰二十一年的固定社會名流，但其財富、作品或行業名聲不自動授予新的機械規則。

## 1. 昊國六大商賈

「六大商賈」是民間約定俗成的稱呼，不是朝廷封爵，也不是一個共同商會。

### 沈萬鈞（「鐵算盤」）—承豐票號

- **總號**：雍京金梁市。
- **生意**：跨道匯兌、商票、漕運墊款與大宗保管。
- **簡史**：五十九歲，從替糧行抄帳起家，在北境軍糧斷款時以自家信用先行兌付而成名。現被普遍視為昊國最富有的私人之一。
- **江湖關係**：僱用多家鏢局而不養私人門派；與戶部合作密切，也長期受御史臺查核。

### 何海生（「潮公」）—四海船盟

- **總號**：東海道海陵。
- **生意**：河海船運、船塢、碼頭倉棧與近海保險分攤。
- **簡史**：六十四歲，船工出身，靠聯合小船戶對抗壟斷碼頭的豪強建立船盟。他重船上規矩，對陸上官場耐性很低。
- **江湖關係**：與蒼龍門合作救難和護航，雙方也常為查船、扣貨與私運責任爭執。

### 烏延金戈（「金駝」）—千里駝行

- **總號**：隴右道赤關。
- **生意**：西關商隊、馬匹、礦石、香料與跨沙海嚮導。
- **簡史**：五十二歲，曾是領路人，熟記長風沙海二十七處季節水源。他不是因滿車黃金得名，而是總在領隊駱駝頸上掛一枚金色小鈴。
- **江湖關係**：常請飛鷲派護送，也向赤煉宮供應礦料；明令駝行不得夾帶人口與軍械私運。

### 蘇半夏（「藥財神」）—濟世藥行

- **總號**：嶺南道南梧。
- **生意**：藥材收購、炮製、醫館供貨與疫病時的跨道調藥。
- **簡史**：四十七歲，出身小藥鋪，靠建立產地、年份與炮製標記制度減少假藥而成巨商。她賺錢毫不避諱，也固定保留一成常用藥作災時平價供應。
- **江湖關係**：與百草閣有公開合作，但百草閣不受藥行指揮；葉春遲等門人偶隨其商隊外診。

### 謝織雲（「十指金」）—雲錦行

- **總號**：江南道澄州。
- **生意**：絲、布、染料、戲服、官服與高級織品。
- **簡史**：五十歲，織戶之女，先改良工錢與交貨合約，再聯合分散作坊建立大行。外號指她十指能辨織物，不是說她點石成金。
- **江湖關係**：長期贊助戲班、書院與鳳羽宮避難工坊；也因此被政敵指責用慈善收買名聲。

### 段百鍊（「火算盤」）—百鍊坊

- **總號**：雲西道雲州。
- **生意**：礦料、農具、標準兵器、精密零件與大型水工器材。
- **簡史**：五十六歲，鐵匠學徒出身，擅長把工匠估時、耗料與返修寫入契約。他出售可靠制式器具，真正名器仍須特定大師與材料，不能量產。
- **江湖關係**：向天機閣採購設計、向刀狂谷請人試鋒，也承接官府水利訂單；三方從未承認百鍊坊擁有其門派武學。

## 2. 文壇六家

### 顧西樓（「史膽」，已故）

昊曆一百五十一年至二百一十六年。官修史局出身，因拒刪太祖晚年錯殺降將一事離職，著《昊史別錄》。他的作品有立場但資料扎實，是研究王朝早期最常引用也最常爭辯的文本。

### 晏清詞（「江左詞宗」，在世）

五十七歲，居澄州。作品以河網、織戶與離鄉者著名，曾用一首長詞迫使地方府衙回應工錢拖欠。她不任官，也不自稱武林中人。

### 陶見山（「萬里筆」，在世）

四十三歲，旅行作家，著《十道山河記》。他親到多數地方，但書中偶爾為行文合併路程；劇本不能只憑他的遊記把兩地實際距離改短。

### 薛小眉（「百戲才子」，在世）

三十五歲，劇作家與班主，常把舊案改寫成戲。她會保護提供素材者的身份，也承認舞臺為戲劇效果改動先後；其戲本可形成線索或輿論，不能當作天然可靠口供。

### 梅鶴年（「一筆龍蛇」，已故）

昊曆一百七十三年至二百三十三年，書法家、碑刻師。其官榜、門匾與私人尺牘遍佈十道，死後仿品激增。單憑「像梅體」不能證明文書年代或真偽。

### 蘇笑生（「說盡天下」，在世）

四十九歲，說書人與《江湖月報》主筆。他把各地逸聞編成易傳唱故事，能令無名事件一夕出名，也常把三分不確定說成十分精彩。本人公開標示哪些是查證消息、哪些是茶樓傳聞。

## 4. 社會名流的遊戲邊界

1. 六大商賈本人、其商號、文壇六家與百業名人都不是自動新增的相對名譽對象；一般依【商賈】、【士紳】、【鏢行護運】等已登錄大類處理，私人關係另存。
2. 富商可以調動銀錢、商路與僱員，但不是無限資源。劇本若讓其提供船、貸款、護衛或情報，須寫明條件、時間、權利與後果。
3. 文豪作品、戲本、書法與說書可影響輿論或成為證物，可靠程度取決於來源與成文過程；名氣不能取代證據。
4. 名醫、工匠、鏢王與航海家仍受時間、材料、距離、傷勢與個人動機限制，不是讓 GM 跳過難題的萬能 NPC。
