# 朝廷與官府

## 蕭氏昊國

昊國由太祖**蕭定川**在昊曆元年結束諸鎮混戰後建立，定都雍京。蕭氏以文官治民、樞密調兵、地方道臺監察府州；皇帝保留對高級軍職、靖武司與重大江湖案件的最終裁決權。

承泰朝的核心矛盾不是「朝廷要消滅所有江湖」，而是朝廷需要門派在偏遠地區護路、救災與牽制豪強，同時又不容任何門派形成能割據州縣的私軍。門派則需要官府承認田產、通行與師承，卻警惕靖武司把合作變成收編。

## 皇室固定人物

### 蕭景衡（承泰帝）

- **身份**：昊國皇帝，四十七歲，在位二十一年。
- **簡史**：年輕時親歷兩位皇兄爭儲引發的京營兵變，登基後先整頓禁軍，再重修靖武約。他能用門派但不輕信門派，也拒絕把所有武人逼成敵人。
- **公開立場**：維持道路、漕運、邊關與稅糧優先；容許門派自治，但反對私設刑獄與擴充武裝。
- **稱呼**：公文稱「皇帝陛下」；臣民口稱「聖上」或「今上」。「承泰帝」是按年號的敘述稱呼，不是江湖外號。

### 蕭元澈（太子）

- **身份**：皇太子，二十五歲。
- **簡史**：自幼受文官與軍將兩系教導，曾匿名隨漕船南行三月，見過地方官、船幫與門派共同維持水路的實況。
- **公開立場**：主張把靖武約條文明文化，讓地方官不能隨意把正規門人當賊，也讓門派不能用口頭祖規逃避刑責。
- **江湖關係**：與玄當派、蒼龍門及天機閣均有公開往來，但不是任何一派弟子。

### 蕭明昭（昭寧長公主）

- **身份**：皇帝胞姊，五十三歲，主持皇室救濟田與陣亡軍戶撫恤。
- **簡史**：京營兵變時曾護送幼弟出宮，後多次以皇室使者身份調停邊軍與門派。她不領正式軍職，卻是朝中少數能讓樞密院、戶部與江湖名宿同席說話的人。
- **江湖稱呼**：「昭寧君」。這是敬稱，不是官銜。

## 三公

三公皆是承泰朝位望最高的輔政重臣。本朝三公官銜為**公師、公傅、公保**；三職能進入重大朝議、受命議禮、議儲與調停官僚衝突，但沒有各自統轄全國官署的獨立行政系統。

三公所代表的三條路線，原本只是官僚處理政務時不同的優先次序：先問名分與制度是否能長久維持、先問政策能否真正執行，或先問法理與程序是否一致。隨著三人長年授業、舉薦、用人，以及學生、門生故吏、同年與地方官員彼此提攜，三種取向已逐漸凝成朝堂三大政治光譜。

| 人物 | 官職／外號 | 政治取向與朝野關係 |
|---|---|---|
| **柳守衡** | 公師／「守經公」 | 六十九歲。世代儒官之家，歷任禮部、國子監與宗正禮議相關差遣。重名分、禮制、官箴與制度延續，是柳系／禮序一系在朝中的最高支點；崇禮社多把他視為能以成例約束權貴的政治典範。 |
| **章濟川** | 公傅／「濟務公」 | 六十四歲。由地方轉運、河工與賑務入中樞。最重政策是否有人、有糧、有錢、有路可做，是章系／經務一系在朝中的最高支點；經世社多把其河工、調糧與賑務政績視為實務政治的樣板。 |
| **沈明矩** | 公保／「直衡公」 | 六十一歲。寒門進士，早年長期任刑獄與地方按察職。重公開規則、程序一致與可覆核的官權，是沈系／法理一系在朝中的最高支點；明理院多把他的判詞與奏議視為法理進入實政的證明。 |

三公不是明理院、經世社或崇禮社的上級，也不能命令院社發文、聯署、募款或停止講學。關係方向更多是由民間向上：三院社主動擁戴理念相近的三公，把他們視為朝中最具代表性的政治人物；三公可以閱讀其文章、採用其調查或推薦其中人才，但不因此取得組織控制權。相關黨爭、院社身份與人才流動見[朝野派系](朝野派系.md)。

## 中央重臣

| 人物 | 官職／外號 | 簡約背景與江湖立場 |
|---|---|---|
| **裴觀瀾** | 中書令、首輔／「鐵筆相公」 | 六十二歲。寒門科舉出身，擅長把模糊慣例寫成可執行法令。支持靖武約，但反對靖武司繞過正常司法。 |
| **韓靖川** | 樞密使／「霜鬢將軍」 | 五十八歲。朔北守將出身，左肩有舊箭傷。與風雷殿、飛鷲派合作多年，認為邊關信用比京城文書更快救命。 |
| **顧慎言** | 御史大夫／「冷面御史」 | 五十一歲。曾彈劾三名封疆大吏，也查過名門侵佔民田。對官員與門派一樣苛刻，因此雙方都有人敬他、也有人恨他。 |
| **杜承穀** | 戶部尚書／「算國手」 | 五十五歲。主理漕糧、鹽課與國庫，與大票號往來密切。相信穩定商路可少養十萬亂兵，卻常被批評過度倚重富商。 |
| **虞定疆** | 鎮北大將軍、定關侯／「北門柱」 | 五十歲，常駐鎮朔。重軍紀、不喜京城派系，允許江湖人立功受賞，但不容門派在軍營自立號令。 |

中央重臣並不按三系平均分布。裴觀瀾與顧慎言在多數法制、監察議題上較近沈系；韓靖川與杜承穀在軍需、漕運與資源調度上常與章系合作。柳系的主要根基則更多分布在禮部、國子監、宗正禮議、地方學官與老牌文官師承網絡。這些接近都不等於受三公私人指揮。

虞定疆是少數刻意不入三系仍能居高位者，主要依靠長年邊功、軍中威望與皇帝直接信任。一般官員若沒有任何穩定師承、舉薦或派系人脈，雖不會因此受罰，卻較難取得好外任、回京、中樞專案與持續升遷機會；因此朝堂上真正長期完全不入三系者只佔少數。

## 與江湖關係最密切的官員

### 沈孤鴻（「烏衣刀」）

- **官職**：靖武司都指揮使，四十四歲。
- **來歷**：少年曾任鏢師，後由軍功入官；懂門派禮數，也熟悉江湖人如何利用禮數說謊。
- **職責**：登記重大門派衝突、聯絡山門、查禁私軍與處理牽涉多道的武人案件。
- **基準立場**：寧可先談判分隔衝突，再抓真正主使；若有人以門派名義庇護大規模劫殺，他會直接調兵。

### 秦照霜（「照夜眼」）

- **官職**：刑部總捕，三十九歲。
- **來歷**：出身地方捕戶，因破獲跨三道的假官印案升入刑部。她曾向霜華閣學過辨認寒勁傷痕的方法，但不是該派正式弟子。
- **職責**：重大命案、跨道通緝、官民證物與地方捕役協調。
- **基準立場**：把武學痕跡視為線索而非身份鐵證；最厭惡官府為求結案逼供替罪者。

### 謝清和（「白簡使」）

- **官職**：禮部客儀司郎中，四十六歲。
- **來歷**：曾任照江知府幕僚，主持過三次鏡湖公議的席次、文書與停戰交換。
- **職責**：朝廷與寺觀、門派、外地使節之間的正式禮儀與誓約文本。
- **基準立場**：相信稱呼、座次與可核對文字能避免很多無謂流血；他沒有權替刑部赦罪。

## 官署與權限

| 官署 | 主要職責 | 與江湖的典型接觸 |
|---|---|---|
| **中書臺** | 政令、任官、全國行政協調 | 決定門派田產、重大敕令與跨部會政策，不直接日常抓人。 |
| **樞密院** | 軍令、邊防、軍鎮 | 借用門派斥候、護送軍資、處理邊境武人與軍紀。 |
| **御史臺** | 監察與彈劾 | 查官員勾結門派、豪強或商號，也查官府濫捕。 |
| **刑部** | 重大刑案、覆核、跨道通緝 | 由總捕協調地方捕役；刑部不是所有地方小案的第一處理者。 |
| **靖武司** | 跨門派衝突、武人情報、私軍與叛亂風險 | 最常直接進山門談判；無權把普通私人恩怨全數變成御案。 |
| **戶部** | 稅糧、鹽課、漕運、國庫 | 與票號、船盟、鹽商、鏢行及地方豪強往來。 |
| **地方府縣** | 治安、賦稅、民刑初審、救災 | 普通百姓最常遇到的官府；能力與廉潔差異很大。 |

中央官署、皇室與地方府州縣同屬昊國官僚體系，但消息、權限與利益並不完全一致。中央命令向地方傳遞需要時間，地方官也常因能力、資源與人脈不同而採取不同做法。

## 武人案件的公開原則

1. **比武不等於合法傷人**：雙方同意的公開比試可成為量刑與責任的情境，但不能合法殺害旁人或事後滅口。
2. **門規不高於刑律**：逐出師門、禁足、收回門內物品可由門派自理；酷刑、終身私囚與處死人命會引來官府介入。
3. **武學痕跡不是唯一證據**：招式可被偷學、模仿、嫁禍或以相似兵器造成。秦照霜公開要求至少結合動機、行蹤、物證或證詞。
4. **通緝有層級**：地方告示未必跨道有效；刑部海捕與皇命緝拿才會動員全國官署。江湖懸賞不是官府判決。
5. **山門可談判，不是治外法權**：地方官通常先送文書要求交人或查證；若門派拒絕且案情重大，靖武司或軍鎮才會升級處置。

## 承泰二十一年的公開政局

- 太子推動把靖武約附例整理成全國通行條文；部分地方官支持，部分門派擔心門籍變成監控名冊。
- 靖王府明確維護既立太子；安王府公開承認太子，但主張在重大失能、失德或危及社稷時仍可依法議改。兩府尚未公開奪嫡，朝中已有人據此分辨彼此的宗室與儲位立場。
- 公保沈明矩、公傅章濟川、公師柳守衡分別成為法理、經務與禮序三條行政取向的朝堂支點；長年師承、舉薦與用人已令三者發展成實際的三大政治光譜，各自爭取任官、政策主導權與下一代官員。
- 明理院、經世社與崇禮社是民間士人議政組織，分別最常擁戴沈明矩、章濟川與柳守衡。三公不能統領院社；相反，各朝堂派系會從相近院社中觀察、舉薦與吸收人才，而入仕者也可能繼續保有院友或社友身份。
- 少數官員刻意不入任何一系，但因缺少穩定師承與舉薦鏈，通常比有派系支持者更難升遷；皇帝直接簡拔、軍功或不可替代的專業能力是主要例外。
- 朔北連年軍費高企，戶部與樞密院為漕糧、馬價與徵調爭論不休。
- 通京大渠數段需要大修，承豐商會旗下票號與其他商家願墊資，御史臺則要求防止以修渠為名圈地。
- 皇帝健康尚可，沒有公開廢立太子的計畫。坊間雖有相反傳聞，但未有可靠證據支持。
- 朝廷沒有剷除主要門派的中央密令。個別官員與軍鎮中存在更強硬的聲音，但不是承泰朝廷的既定共同政策。
