# 人文

本層描述人們怎樣生活、交易、學習、傳播消息與看待外來者，不保存具名人物／組織的完整資料。

- [`社會與生活.md`](社會與生活.md)：文字、貨幣、身份、交通與日常社會。
- [`商業與百業.md`](商業與百業.md)：商業生態、鏢運、工藝與城市百業。
- [`文壇與信息傳播.md`](文壇與信息傳播.md)：書院、文壇、戲曲、說書與輿論。
- [`外來商旅與海外往來.md`](外來商旅與海外往來.md)：外國存在、西海商船及南北外來商團的基準尾巴。

具名商會、樓館、人物等請沿連結進入 [`../組織/`](../組織/README.md) 或 [`../人物/`](../人物/README.md)。
