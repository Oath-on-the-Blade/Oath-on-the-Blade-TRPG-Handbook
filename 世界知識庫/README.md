# 世界知識庫：昊國世界觀

本目錄是《武與俠》共用虛構世界的權威入口。它固定**昊國、政治地理、歷史基準、門派沿革、著名人物、朝廷、商賈、文壇、綠林與江湖傳聞**；遊戲機制仍由 `遊玩規則/` 與 `內容庫/` 定義。

所有未明列其他時點的獨立劇本，預設從**昊曆二百四十一年／承泰二十一年**的基準狀態開始。某桌遊戲已經造成的人物死亡、門派易主、城池損毀或政局變化，屬該 `game_id`／戰役的持續世界狀態，優先於本目錄的起始基準；不反向改寫 Handbook 正典。

## 分類索引與讀取順序

1. [`時代與世界基準`](世界基準/時代與世界基準.md)：所有使用昊國舞台的工作先讀；含時代、現實武俠邊界、朝廷與江湖的基本關係。
2. [`昊國地理`](地理/昊國地理.md)：涉及地區、城市、山川、湖泊、道路、長途旅行或地方官署時讀。
3. [`朝廷與官府`](政權/朝廷與官府.md)：涉及皇室、中央官員、軍鎮、刑案或官府—江湖關係時讀。
4. [`十六門派`](勢力/門派.md)：涉及正式具名門派、祖師、現任首領、門內稱呼、高層與著名後進時讀。
5. [`江湖人物與武學源流`](人物/江湖人物與武學源流.md)：涉及著名散修、名宿、已故俠者或無門派武學源流時讀。
6. [`商賈、文壇與百業`](社會/商賈文壇與百業.md)：涉及大商號、富商、文豪、名醫、工匠、名伶、鏢行與其他社會名流時讀。
7. [`綠林、黑道與神秘人`](江湖/綠林黑道與神秘人.md)：涉及大山賊、水寇、走私、暗殺者、身份不明人物或隱世俠者時讀。
8. [`年表與關係`](歷史/年表與關係.md)：涉及歷史先後、門派舊怨、結盟或跨地區政治背景時讀。

## 權威邊界

- **共用世界基準是甚麼**：`世界知識庫/`
- **角色、判定、戰鬥、成長與社會名譽怎樣運作**：`遊玩規則/`
- **可直接引用的武學、物品、敵人與正式相對名譽對象是甚麼**：`內容庫/`
- **一份劇本獨有的真相、當前人物狀態、場景與結局是甚麼**：該最終劇本 md
- **某桌已發生並需延續的結果是甚麼**：該 `game_id`／戰役的最新有效存檔
- **GM 如何載入、主持與保存上述資料**：`GM規則/`

`世界知識庫/` 只定義虛構事實，不授予 AC、氣血、攻擊加值、武學等級、傳承上限、相對名譽 `c` 或其他機械數值。人物被稱為宗師、名宿、高手或神捕時，若要在劇本內登場，劇本仍須依正式規則提供足以運行的 NPC 層級、能力、目的、認知、行動與撤退條件。

## 固定正典與刻意未知

1. 本目錄明列的姓名、外號、身份、職位、門派首領稱呼、生死狀態、創立事蹟與地理位置，均是承泰二十一年基準正典。
2. 「已故」表示在基準時點前已死亡；一般獨立劇本不得讓其以仍在人世的身份出現。
3. 「真名不詳」「身份不詳」「下落不明」是**刻意保留的正典未知**，不是任由單一劇本把某個答案升格為全 Handbook 真相。劇本可提出傳聞、冒名者或該桌限定答案，但必須清楚標成局部／戰役狀態。
4. 外號不等於真名。只有本目錄明列真名者，才可把該真名當成共用世界事實。
5. 本目錄沒有暗藏 GM 專用反轉；「傳聞未定」的事項就是基準世界尚無定論。劇本若需要確定答案，必須把該答案及其適用範圍完整寫在劇本內。

## 劇本新增與改變世界

劇本可以新增地方村鎮、支派、商號、官員、俠客、山寨與歷史小事，只要：

- 不與本目錄已固定的國號、年代、地理從屬、人物身份、生死、門派首領或武學源流矛盾；
- 不把新增人物冒充已固定人物，不把既有外號轉授他人；
- 不要求 GM 只靠本目錄補完該劇本專用的真相或運行資料；
- 若劇本結局可能改變固定人物或勢力，明寫變化、成立條件與後續保存方式，並把它視為該桌世界狀態，而不是自動更新所有獨立劇本的起點。

引用固定人物時，劇本仍為其配置本劇本內唯一 NPC ID，姓名使用完整固定格式，例如 `<NPC#3: 蕭-景衡>`；同一人物在該劇本所有位置保持同一 ID。只有法號或外號可用、真名受保留的人物，可把固定顯示稱呼拆入同一語法，例如 `<NPC#4: 白-影>`，並在人物條目明寫「顯示稱呼：白影；真名不詳」；這個技術分隔不表示其姓白名影。若該人物同時是明確前作再次登場的 NPC，仍依 `劇本設計規則/設計.md` 使用 `@前作劇名` 來源標記。普通劇本專用 NPC 則繼續使用可變姓名欄位。

## 與相對名譽的關係

世界中存在一個具名人物、商號、官署、山寨或團體，**不表示它自動成為相對名譽數值對象**。可用對象與 `c` 值只以 `內容庫/相對名譽對象.md` 為準。

承泰二十一年目前已正式登錄的世界對象包括：

- **朝廷**與**十道官府**分開保存；中央官署／跨道中央權力使用【朝廷】，一道內一般府州縣與地方官面使用對應【某道官府】；
- **十道民間**各自保存地域共同觀感，不再存在一個全國【民間】母值；
- **十六個正式具名門派**各自保存；
- **六大商賈**的核心事業各自保存：【承豐票號】【四海船盟】【千里駝行】【濟世藥行】【雲錦行】【百鍊坊】；
- **五大綠林**各自保存：【摩天寨】【白浪水寨】【赤旗十八寨】【烏鴉嶺】【斷關盟】；
- 世界知識庫尚未足以再細分的專業圈，才使用 `內容庫/相對名譽對象.md` 當前列出的泛類。

單一固定人物的恩義、仇怨、承諾與私人態度，仍保存為人物／世界狀態，不另創相對名譽數值。世界知識庫日後新增商號、山寨、官署或其他勢力時，也不會自動取得相對名譽；需要持久機械數值時先修訂登錄表。

## Markdown 格式

1. 每個檔案只使用一個 `#` 一級標題。
2. 固定人物第一次出現時寫「姓名（外號／法號／官稱）」；後文可用最常見稱呼。
3. 同一人物若同時有職位與江湖外號，職位描述與外號分開，不把外號誤當官銜。
4. 新增正典時同步檢查本目錄索引、`README.md`、`劇本設計規則/`、`GM規則/` 與 `Instruction模版.md` 的讀取路由。
