# 世界知識庫

本目錄保存《武與俠》共用世界正典。資料分成兩種：

1. **面向文件**：回答「世界如何運作」，放在 `地理與世界基準/`、`人文/`、`政治/`、`江湖/`。
2. **實體權威文件**：回答「某個具名組織／人物是誰」，只放在 `組織/`、`人物/`。

## 頂層路由

- [`地理與世界基準/`](地理與世界基準/README.md)：年代、物理／技術基準、十道、城市、山川、路程與歷史年表。
- [`人文/`](人文/README.md)：社會生活、商業文化、文壇傳播、外來商旅與海外往來。
- [`政治/`](政治/README.md)：國家架構、官僚制度、宗室繼承、朝堂三系與當前政局。
- [`江湖/`](江湖/README.md)：江湖秩序、靖武約、門派格局、黑道綠林與當前關係。
- [`組織/`](組織/README.md)：所有具名組織的唯一權威條目，可按政治與官僚、商業、江湖等分類。
- [`人物/`](人物/README.md)：所有固定人物的唯一權威條目，可按主要身份分類；跨類別人物只保留一個主檔，其餘索引以連結指向。

## 權威原則

- 面向文件可以概括、比較與描述關係，但**不得另存一份完整人物／組織資料**。
- 某人物的年齡、生死、身份、背景與個人立場，以 `人物/` 下其單一檔案為準。
- 某組織的所在地、結構、領導職位、宗旨、資源與組織立場，以 `組織/` 下其單一檔案為準。
- 人物與組織之間、組織與地理之間、不同面向之間都以 Markdown 連結互通。
- 若總覽與實體權威檔出現衝突，應視為知識庫需修復；AI GM 臨時判讀時優先採實體權威檔。

## AI 最小讀取

先讀本 README，判斷問題屬於哪一個面向；只有問題涉及具名人物／組織時才沿連結讀該實體檔。不要為了查一個王府、商會或門派預載整個類別。
