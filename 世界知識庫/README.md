# 世界知識庫

> **Note｜索引、權威與生成**
> - `地理與世界基準/`、`人文/`、`政治/`、`江湖/` 用於描述世界如何運作、宏觀狀態與跨實體關係；具名組織與人物的完整資料分別以 `組織/`、`人物/` 下的單一條目為權威。
> - 人物的年齡、生死、身份、背景與個人立場以人物條目為準；組織的所在地、結構、領導職位、宗旨、資源與組織立場以組織條目為準。總覽與實體條目若衝突，應修正總覽而非自行合併。
> - 生成局部內容時可在不衝突前提下加入臨時人物、地點、事件與小型實體；若升格為持續存在、會被跨劇本引用的具名人物或組織，應建立對應條目並由其他文件連結引用。

- [`地理與世界基準/`](地理與世界基準/README.md)：年代、自然與武學、十道、城市、山川、路程與歷史。
- [`人文/`](人文/README.md)：社會生活、商業文化、文壇傳播、外來商旅與海外往來。
- [`政治/`](政治/README.md)：國家架構、官僚制度、宗室繼承、朝堂三系與當前政局。
- [`江湖/`](江湖/README.md)：江湖秩序、靖武約、門派格局、黑道綠林與當前關係。
- [`組織/`](組織/README.md)：朝廷官署、王府、院社、商會、鏢局、幫會、門派與綠林。
- [`人物/`](人物/README.md)：政治、商業、江湖與人文人物。
