# 國家與官僚架構

昊國由太祖蕭定川在昊曆元年結束諸鎮混戰後建立，定都雍京。蕭氏以文官治民、樞密調兵、地方道臺監察府州；皇帝保留對高級軍職、靖武司與重大江湖案件的最終裁決權。

承泰朝的核心矛盾不是「朝廷要消滅所有江湖」，而是朝廷需要門派在偏遠地區護路、救災與牽制豪強，同時又不容任何門派形成能割據州縣的私軍。門派則需要官府承認田產、通行與師承，卻警惕靖武司把合作變成收編。

中央主要制度節點包括 [`中書臺`](../組織/政治與官僚/中書臺.md)、[`樞密院`](../組織/政治與官僚/樞密院.md)、[`御史臺`](../組織/政治與官僚/御史臺.md)、[`刑部`](../組織/政治與官僚/刑部.md)、[`靖武司`](../組織/政治與官僚/靖武司.md)、[`戶部`](../組織/政治與官僚/戶部.md)，以及各道府州縣官府。

三公皆是承泰朝位望最高的輔政重臣。本朝官銜為**公師、公傅、公保**；三職能進入重大朝議、受命議禮、議儲與調停官僚衝突，但沒有各自統轄全國官署的獨立行政系統。三公與朝堂三系的政治關係另見 [`朝堂三系與黨爭.md`](朝堂三系與黨爭.md)。

中央官署、皇室與地方府州縣同屬昊國官僚體系，但消息、權限與利益並不完全一致。中央命令向地方傳遞需要時間，地方官也常因能力、資源與人脈不同而採取不同做法。

## 武人案件的公開原則

1. **比武不等於合法傷人**：雙方同意的公開比試可成為量刑與責任的情境，但不能合法殺害旁人或事後滅口。
2. **門規不高於刑律**：逐出師門、禁足、收回門內物品可由門派自理；酷刑、終身私囚與處死人命會引來官府介入。
3. **武學痕跡不是唯一證據**：招式可被偷學、模仿、嫁禍或以相似兵器造成。刑部總捕秦照霜公開要求至少結合動機、行蹤、物證或證詞。
4. **通緝有層級**：地方告示未必跨道有效；刑部海捕與皇命緝拿才會動員全國官署。江湖懸賞不是官府判決。
5. **山門可談判，不是治外法權**：地方官通常先送文書要求交人或查證；若門派拒絕且案情重大，靖武司或軍鎮才會升級處置。
