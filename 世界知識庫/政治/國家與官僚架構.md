# 國家與官僚架構

昊國由蕭氏皇室統治，文官治民、樞密調兵、地方道臺監察府州；皇帝保留對高級軍職、靖武司與重大江湖案件的最終裁決權。

中央主要制度節點包括 [`中書臺`](../組織/政治與官僚/中書臺.md)、[`樞密院`](../組織/政治與官僚/樞密院.md)、[`御史臺`](../組織/政治與官僚/御史臺.md)、[`刑部`](../組織/政治與官僚/刑部.md)、[`靖武司`](../組織/政治與官僚/靖武司.md)、[`戶部`](../組織/政治與官僚/戶部.md)，以及各道府州縣官府。

三公是位望最高的一組輔政重臣，本朝官銜為**公師、公傅、公保**。三職能進入重大朝議、受命議禮、議儲及調停官僚衝突，但沒有各自統轄全國官署的獨立行政系統。

## 武人案件公開原則

1. 比武不等於合法傷人；同意比試不能合法殺害旁人或事後滅口。
2. 門規不高於刑律；逐出、禁足、收回門內物品可由門派自理，酷刑、終身私囚與處死人命會引來官府介入。
3. 武學痕跡不是唯一證據；招式可能被偷學、模仿或嫁禍。
4. 通緝有層級；地方告示未必跨道有效，刑部海捕與皇命緝拿才會動員全國官署。
5. 山門可談判，但不是治外法權。

中央命令向地方傳遞需要時間，地方官也會因能力、資源、人脈與廉潔程度不同而採取不同做法。
