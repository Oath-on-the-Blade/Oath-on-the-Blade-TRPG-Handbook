# 遊玩規則

此目錄只收錄《武與俠》的**遊戲機制本身**：角色建立、判定、戰鬥、資源、武學、成長、探索與 NPC 快速數值。

它回答的是「遊戲規則是甚麼」，不負責說明 AI／GM 應如何主持，也不負責說明劇本作者應如何設計或驗收劇本。

- GM 主持方法：見 [`../GM規則/README.md`](../GM規則/README.md)
- 劇本設計與驗收：見 [`../劇本設計規則/README.md`](../劇本設計規則/README.md)
- 可直接引用的武學、裝備、藥物與敵人：見 [`../內容庫/README.md`](../內容庫/README.md)
