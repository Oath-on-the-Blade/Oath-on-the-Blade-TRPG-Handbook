# 金錢與購買力

本文件提供《武與俠》共用的**銀兩購買力、日常生活、常見服務與世界內報價基準**。它不是要模擬完整歷史經濟，而是讓不同劇本、GM 與玩家對「一兩銀究竟值多少」有共同尺度。

具體裝備、藥物、材料、坐騎或其他已有正式內容庫條目的物件，以該條目標價與取得限制為準；本文件的區間只用於沒有更具體權威條目時的常態參考。

---

## 1. 基本計價原則

- 一般計價單位為**銀兩**；小額日常支出可以用小數兩表示，敘事上亦可寫成「數錢」。本規則不額外固定銅錢與銀兩的歷史換算比例。
- `內容庫/裝備與物品.md` 的具體標價是標準市場取得價；地方供應、戰亂、封鎖、門派配給、熟人優惠或黑市風險若會實際改價，須由當前世界狀態或劇本另行說明。
- 標價代表一般取得成本，**不保證可隨時原價轉售**。二手、贓物、受限物品、特殊材料或缺乏買家的物件，出售能力與售價取決於實際市場、合法性、狀態與買家。
- 角色有錢不代表任何物件都必然可買到。珍稀物品、名器、秘笈、受限藥毒、特殊坐騎與具政治／門派性質的權利，仍受取得條件限制。

## 2. 購買力錨點

以下用現有核心價格作共用直覺尺度：

| 金額 | 常見購買力感覺 | 既有錨點／例子 |
|---:|---|---|
| 0.05–0.2 兩 | 小額日常消費 | 一頓普通餐食約數錢 |
| 0.5–1 兩 | 一次普通食宿或數日基本補給 | 普通客棧一晚約半兩至一兩；三日乾糧 1 兩 |
| 3–5 兩 | 一批旅行消耗品、小工具或短期服務 | 旅行包 3 兩；常見小型工具／消耗品多落在此附近 |
| 8–15 兩 | 一件正常江湖兵器或一名新角色的主要現金尺度 | 建議起始現金 10 兩；普通兵器約 5–15 兩 |
| 20–30 兩 | 明顯較好的裝備、工具或一筆有份量的儲備 | 內容庫 6–30 兩屬「精良」價格帶 |
| 31–100 兩 | 昂貴資產、重裝備或足以改變短期財務狀態的一筆錢 | 內容庫 31–100 兩屬「昂貴」價格帶 |
| 100 兩以上 | 珍稀資產、優良坐騎、高價特殊裝備或劇情級財務事件 | 內容庫 100 兩以上屬「珍稀」價格帶 |

這些是**購買力錨點**，不是說所有同價物件在世界內都同樣容易取得。例如 100 兩可以買到某些昂貴裝備，不等於一定能買到一門武學、名器或某個官面資格。

## 3. 日常生活與一般收入

以下是正常治安、供應穩定地區的常態參考。若劇本不需要精細經濟，不必逐餐逐日扣款；只有當金錢、補給、旅行成本、談判或資源壓力實際影響選擇時才需要使用。

### 3.1 生活支出

| 項目 | 常態參考 |
|---|---:|
| 普通一餐 | 0.05–0.2 兩 |
| 簡單客棧一晚 | 0.5–1 兩 |
| 一人一天普通食宿合計 | 約 0.6–1.5 兩 |
| 一人一月節儉生活 | 約 6–12 兩 |
| 一人一月較舒適生活 | 約 15–30 兩 |
| 富足／講究生活 | 約 50 兩／月以上 |

月度生活費是長期購買力比較，不要求一般短篇逐月結算。

### 3.2 一般工錢與專業日薪

| 工作 | 常態參考 |
|---|---:|
| 普通短工、腳夫、雜役 | 約 0.2–0.4 兩／日 |
| 熟練工匠、書手、普通專業技工 | 約 0.5–1 兩／日 |
| 一般護院、持械護衛 | 約 0.5–1.5 兩／日 |
| 有經驗鏢師、嚮導、危險地區專業人手 | 約 1–3 兩／人／日，另計必要成本 |
| 名家、高手、極高風險或高度敏感服務 | 不設統一日薪；按身份、風險與稀缺性議價 |

玩家角色接受的是**有失敗風險、戰鬥風險、責任與成功條件的江湖任務**，不能單純把上述普通日薪乘天數就當作完整冒險酬勞；任務報價還需要風險、成功價值、保密、名聲、急迫性與委託人財力等溢價。

## 4. 常見服務與交通

沒有正式內容庫條目時，可用以下範圍作常態起點：

| 項目 | 常態參考 |
|---|---:|
| 小額跑腿、傳話、一般帶路 | 0.2–1 兩 |
| 一日普通嚮導／信使 | 0.5–1.5 兩 |
| 城內／近郊短程車船 | 0.1–0.5 兩／人 |
| 短程包車、包船或載貨 | 約 0.5–2 兩起，按距離與載重增加 |
| 普通馬匹短期租用 | 約 1–3 兩／日，通常另有押金或保證 |
| 普通可長途騎乘馬匹 | 約 40–70 兩 |
| 良馬／快馬 | 約 100–200 兩以上；稀有血統或名駒可更高且未必公開出售 |
| 普通診察、處理小傷病 | 約 0.5–2 兩 |
| 嚴重外傷／內傷的一次處置 | 約 2–10 兩，特殊藥材另計 |
| 名醫、罕見療法或高風險治療 | 約 10–50 兩以上，亦可能需要人情或資格而非單純金錢 |
| 普通地方消息、小費式情報 | 約 0.1–1 兩 |
| 有用而非公開的地方情報 | 約 0.5–3 兩 |
| 有風險的秘密、內部消息 | 約 5–20 兩 |
| 重大機密、官面賄賂、會牽連身份的情報 | 20 兩以上且高度依人物、風險與關係決定 |

賄賂與秘密情報不是固定商品。表中數值只表示「這種代價已屬甚麼購買力級別」，不保證 NPC 收錢，也不取代社會互動、利益與風險判斷。

## 5. 地區與局勢修正

沒有更具體世界資料時，可把上述價格視為 `×1.0` 常態。若當地差異需要實際影響遊戲，可參考：

- **物資充裕、鄉郊低成本**：相關日常項目約 `×0.7–0.9`。
- **繁華城市、旺季、特殊地段**：相關項目約 `×1.1–1.5`。
- **戰亂、封鎖、災害、斷糧、急缺運力**：受影響項目可達 `×1.5–3` 或更高。
- **門派／組織內部配給**：可免費、折價或記帳，但必須有身份與資源來源。
- **違禁／黑市項目**：除了價格，還要考慮能否找到賣家、查緝風險、信任與後果；不得只用倍率把合法市場價改成黑市價便算完成。

不要把單一地區倍率機械地套在所有項目上。糧荒可以令食物暴漲，卻不代表本地每一把舊刀、每一項工錢與每一間客棧都必定同比上漲。

## 6. 金錢對遊戲面的意義

判斷一筆金錢是否「大」時，優先問它能改變甚麼：

- **1 兩左右**：數日基本生活／補給。
- **10 兩左右**：一件普通武器，亦等於新角色建議起始現金。
- **30 兩左右**：已能購置一件明顯較好的裝備或承擔一段不短的生活成本。
- **100 兩左右**：足以購置昂貴護具、良馬級資產或形成顯著長期財務變化。
- **數百兩**：若直接落入一般角色手中，通常已是劇情級資產變動；劇本應有相應委託人財力、風險、所有權、分配與後續影響。

因此同樣是「50 兩」，對一宗一晚跑腿與對一宗跨道護送代表完全不同的合理性。世界內報價首先由因果決定，遊戲面再用購買力檢查是否失真。
