# 遊玩流程路由

本目錄只處理角色已進入遊戲世界後，**目前應使用哪一個遊玩流程狀態**。它不是另一份主持規則，也不重複角色建立、內容庫或劇本設計要求。

遊玩中有三個可反覆切換的主要迴圈：【主探索迴圈】、【整備與安全空檔】、【戰鬥】；當本次劇本已停止接受新的正常遊戲行動時，切入終止狀態【結算】。結算開始後不再返回前三個迴圈，除非只是先前誤判劇本已結束而尚未真正凍結結果。

## 整備與安全空檔

讀：[`整備與安全空檔.md`](整備與安全空檔.md)

適用於：
- 出發前整備；
- 短休、長休；
- 製作、修習、研究、療傷或其他有正式工時的活動；
- 劇本或當前情境明確提供、而角色可自行分配的安全時間。

此檔只負責共同時間機制與可執行行動入口：30 分鐘空檔回合、長活動、並行、一般協助、共同操作、中斷、出發前整備及休息。

複雜行動不在此檔重寫：
- 製作、料理、乾糧、藥毒與特殊材料：`遊玩規則/系統與機制/製作與材料.md`
- 武學修習與成長：`遊玩規則/角色/升級與武學成長.md`
- 裝備、攜帶格與物品本身：`遊玩規則/系統與機制/裝備基礎.md` 與 `內容庫/裝備與物品.md`

## 主探索迴圈

讀：[`主探索迴圈.md`](主探索迴圈.md)

適用於沒有進入戰鬥、也沒有正在以安全空檔結算正式長活動時的大部分遊戲時間，包括：
- 場景移動與長途旅行；
- 世界時間與跨日結算；
- 食物、飲水與疲勞；
- 追逐；
- 搜查、推理與一般社交；
- NPC／遭遇快速數值。

主探索迴圈負責把一般行動結果重新帶回世界時間與局勢，並判斷是否需要切入安全空檔、戰鬥或結算。

## 戰鬥

讀：[`戰鬥.md`](戰鬥.md)

適用於需要以先攻、輪次、動作、隨附動作與反應精確結算的敵對衝突。

戰鬥中的傷害、0 氣血、死亡與共同異常狀態另讀：
- [`傷害與異常狀態.md`](傷害與異常狀態.md)

戰鬥結束、雙方脫離或衝突不再需要逐回合結算後，通常回到【主探索迴圈】；只有世界狀態同時容許角色自由分配安全時間時，才切入【整備與安全空檔】。若該場戰鬥的結果已直接確定本次劇本終局，先完成同一事件必須結算的傷害、死亡、狀態與反應，再切入【結算】。

## 結算

讀：[`結算.md`](結算.md)

【結算】不是第四個可反覆循環的遊玩迴圈，而是本次劇本的**終止流程狀態**。適用於：

- 完成結局已成立；
- 失敗結局已成立且沒有繼續處理的有效核心目標；
- 玩家已確認任務放棄／提前撤離並完成必要世界後果收束；
- 劇本明列的其他終止條件成立。

此檔負責：
- 判斷何時停止接受新的正常遊戲行動；
- 完成已開始且直接決定終局事實的必要結算；
- 固定最後的角色資源、物品、狀態與世界結果；
- 防止在結局成立後把結算當成免費休息、購物、製作或追加搜刮時間；
- 把凍結後的遊戲機械狀態交給 `GM規則/結算.md`。

歷練、角色卡寫回、江湖履歷、社會名譽、長期特殊傷患、結算憑證及存檔關閉等 GM 程序仍由 `GM規則/結算.md` 負責。

## 路由優先序

同一時點只使用一個主要流程狀態：

1. **劇本終止條件已成立，而且已停止接受新的正常遊戲行動** → 【結算】；
2. 否則，已進入需要先攻與逐回合精確結算的敵對衝突 → 【戰鬥】；
3. 否則，若角色有一段可自行分配而且足以追蹤正式工時的安全時間 → 【整備與安全空檔】；
4. 其他情況 → 【主探索迴圈】。

不要因為「看起來快結束」便提前進入結算。若一項已宣告行動、戰鬥傷害或其他正在結算的事件仍可能改變劇本是否真正結束，先完成該事件，再判斷終止條件。

複雜子系統不會取代主要流程狀態。例如角色在安全空檔中製藥時，主要迴圈仍是【整備與安全空檔】，只是該項行動的材料、DC、批量與失敗結果改查【製作與材料】；戰鬥中使用武學時，主要迴圈仍是【戰鬥】，武學條目只提供該次行動的具體效果。進入【結算】後則不再開啟新的安全空檔、探索或戰鬥行動。
