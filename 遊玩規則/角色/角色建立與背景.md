# 角色建立與背景

**第一章　角色建立**

## **1\. 建角流程**

**所有新建立的玩家角色一律由1級開始。** 不直接建立高等級新PC；角色之後依正式遊戲中的成長規則提升等級。新角色的歷練池從 **0 點**開始；升級所需歷練依 `遊玩規則/角色/升級與武學成長.md`。既有角色進入新劇本時不視為重新建角，其既有等級、剩餘歷練與持續狀態依 GM 規則處理。

> 1. 決定角色概念、姓名、年齡與江湖目標。  
> 2. 選擇一個出身背景。  
> 3. 決定六項能力值。  
> 4. 選擇 4 項熟練拿手。  
> 5. 選擇 2 項擅長豁免。  
> 6. 選擇 1 套起始內功，並記錄具體來源與解鎖上限。  
> 7. 選擇 1 套起始外功並記錄來源與解鎖上限；角色由 0 級升至 1 級所得的第 1 點外功等級點自動投入此套外功，使其成為 1 級。  
> 8. 創建或選擇 1 套起始輕功，並記錄具體來源與解鎖上限。  
> 9. 選擇武器、護具與起始物品。  
> 10. 設定俠名、惡名、名氣、相對名譽與門派身份。  
> 11. 寫下至少一項信念、一項牽掛與一項長期目標。

內功與輕功沒有主要／次要身分。建角選定的只是角色最初已入門的一套內功與一套輕功；日後可依正式修習規則掌握更多。各套已入門內功與輕功均按角色等級與自身可修上限自動計算有效等級，不使用武學等級配點。任務開始時的內功選用與輕功使用／更換時機分別依 `遊玩規則/系統與機制/內功.md`、`遊玩規則/系統與機制/輕功.md`。

若角色使用「門派子弟」背景，而且某套起始武學確實來自該門派的建角前基礎訓練，該套武學的來源依第二章記為 `[來自〈門派〉]`，預設解鎖至10級。家傳、散修師父、秘笈或其他獨立來源依自身上限處理，不因角色有門派身份而自動加門派來源標籤。

1級角色只有一套已掌握外功，因此第一次任務中該套外功自然配置為主外功，沒有次外功。外功等級點、任務主／次外功配置與次外功有效等級見 `遊玩規則/系統與機制/外功.md` 與 `遊玩規則/角色/升級與武學成長.md`。

標準拿手完整列表見 `內容庫/拿手.md`；絕活取得規則見 `遊玩規則/角色/絕活.md`，完整絕活條目見 `內容庫/絕活.md`。

## **2\. 六項能力值**

### **力量（Strength）**

爆發力、負重、推拉、重兵器、剛猛拳掌、強行格擋。

### **敏捷（Dexterity）**

身法、反應、潛行、暗器、輕靈武學、輕功。

### **體質（Constitution）**

氣血、耐力、抗毒、疲勞、維持運功。

### **智力（Intelligence）**

學問、機關、醫毒、推理、武學理論。

### **直覺（Sense）**

察覺、洞察、危機感、修心、感應、野外經驗。

### **魅力（Charisma）**

說服、威嚇、欺瞞、領導、江湖氣場。

### **能力值生成**

預設使用標準陣列：**15、14、13、12、10、8**，自由分配。  
可選擲骰：每項擲 4d6，捨棄最低一顆，六組結果再自由分配。

### **能力修正值**

修正值 \= floor((能力值 \- 10) / 2)。

| 能力值 | 修正 |
| ----: | ----: |
| 8–9 | -1 |
| 10–11 | +0 |
| 12–13 | +1 |
| 14–15 | +2 |
| 16–17 | +3 |
| 18–19 | +4 |
| 20 | +5 |

一般能力上限為 20；特殊武學或傳奇效果才可突破。

## **3\. 熟練加值**

| 角色等級 | 熟練加值 |
| :---- | ----: |
| 1–4 | +2 |
| 5–8 | +3 |
| 9–12 | +4 |
| 13–16 | +5 |
| 17+ | +6 |

熟練加值用於：

> * 熟練拿手  
> * 熟練武器攻擊  
> * 擅長豁免  
> * 內功攻擊與內功 DC  
> * 外功招式要求的武學檢定

「專精」代表熟練加值加倍，同一判定最多加倍一次。

## **4\. 衍生數值**

### **氣血上限**

1 級：8 + 體質修正值。  
2 級起每升一級：

> * 擲 1d8 + 體質修正值 增加氣血上限；或  
> * 使用固定值 5 + 體質修正值。

每級至少增加 1 點。

### **氣血骰**

角色擁有等同角色等級數量的 **d8 氣血骰**。短休時可消耗氣血骰療傷。部分內功也會消耗或恢復氣血骰。

### **防禦 AC**

> * 無甲：10 + 敏捷修正值  
> * 輕甲：11 + 敏捷修正值  
> * 中甲：13 + 敏捷修正值（最多 +2）  
> * 重甲：16

同類護具不疊加。武學提供的 AC 加值依招式敘述處理。

### **先攻**

1d20 + 敏捷修正值。

### **基礎步速**

30 尺／回合。種族或體型差異若有需要，由團隊在建角時約定。

### **被動察覺**

10 + 直覺修正值 + 熟練加值（若熟練感應或相關拿手）。

## **5\. 豁免**

建角時選擇兩項能力作為「擅長豁免」。  
豁免：1d20 + 對應能力修正值 + 熟練加值（若擅長）。

常見：

> * 力量：抗推、抗擒拿  
> * 敏捷：避開範圍攻擊、陷阱  
> * 體質：抗毒、疲勞、維持專注  
> * 智力：識破複雜幻術、精神推演  
> * 直覺：抗恐懼、魅惑、感官干擾  
> * 魅力：抵抗意志壓迫、身份／靈魂類影響

**第二章　出身背景**

## **1\. 背景規則**

預設只選一個背景。每個背景提供：

> * 1 個固定能力加值 +1；  
> * 從兩項候選中選 1 項 +2；  
> * 從該背景的「背景特性／物品／資源」中選 **3 項**。

若團隊容許混合背景，可混合 2–3 個背景，但最後仍只得到：

> * 一個固定 +1；  
> * 一個候選 +2；  
> * 三項背景利益。

同一能力值在建角後通常不得高於 17。

每套起始武學都必須有可核對的來源。無門派角色可使用家傳、散修師父、完整秘笈或其他與背景相符的來源；除非背景明寫為殘卷或有限傳授，這類獨立建角來源通常可解鎖至20級。**門派正式訓練是例外**：門派子弟只對角色卡實際選定、且確實由本派基礎訓練取得的起始武學建立 `[來自〈門派〉]` 來源，預設解鎖至10級；加入門派身份不會擴張成全派武學資格。完整門派規則見 `遊玩規則/角色/門派系統.md`。

背景利益若寫「熟悉一門武學」、持有秘笈、具師承、武學天賦或其他學習機會，**只按該利益明文提供其效果**。這些敘述可構成武學來源或學習資格，但不會直接授予額外武學等級、外功等級點或已解鎖招式；正式掌握、來源解鎖上限與提升流程依 `遊玩規則/角色/升級與武學成長.md`。

### **背景利益共同規則**

- 背景利益授予的拿手熟練是建角 4 項熟練拿手之外的額外熟練。若角色已因其他來源熟練同一拿手，而利益沒有明寫「若已熟練則專精」，改從同一背景合理範圍內選擇另一項尚未熟練拿手；不得藉重複取得而自行變成專精。
- 背景利益授予的武器熟練同樣是額外熟練；若已熟練，可改選另一種核心武器。
- 背景物品均使用 `內容庫/裝備與物品.md`、`內容庫/藥物/` 的正式條目。若利益列出價格上限，以內容庫標價為準。
- 背景帶來的社交優勢只在身份、關係或情境真正相關時適用；不會強迫 NPC 違反核心利益，也不等於精神控制。
- 背景利益若提供一次性物品，使用後正常消耗，不會在每個新劇本自動補回。

## **2\. 標準背景**

### **門派子弟**

固定：體質 +1；候選：力量 +2 或 智力 +2。選擇時指定一個門派；三項背景利益中必須包含「正式師承」。可選利益：

> * **正式師承**：你是指定門派的正式弟子。建角時起始內功、起始外功、起始輕功中，凡實際選擇該門派正式武學並以本派基礎訓練作來源者，逐門記錄 `[來自〈門派〉]`，預設解鎖至10級。這不會額外取得任何武學，也不會讓門派其他公開武學自動取得資格；10級以上依門派專用任務或其他正式來源解鎖。  
> * **武學基礎**：指定一門與師承相符的武學。若你已實際掌握它，第一次針對該武學的學習／研究檢定有優勢；若尚未掌握，這項利益只提供熟悉與研究基礎，不會跳過正式入門或建立額外解鎖來源。  
> * **門派資源**：在己方勢力正常控制範圍內，可取得普通食宿、基本療養場所與非機密通行協助；每份劇本整備時的免費門派任務配給另依 `遊玩規則/角色/門派系統.md`，不是本背景利益額外再領一份。  
> * **人脈廣博**：與正規武林勢力交涉時，若你的門派身份或介紹確實有幫助，第一次相關社交檢定有優勢。  
> * **初級武器與護具**：取得一件價格不高於 15 兩的普通武器，以及一件價格不高於 10 兩的普通護具。  
> * **一份門派秘藥**：取得一份內容庫中價格不高於 20 兩的解毒／療傷藥或丹藥。

### **江湖遊俠**

固定：敏捷 +1；候選：直覺 +2 或 智力 +2。可選利益：

> * **匿蹤高手**：取得隱密熟練。  
> * **察言觀色**：取得洞察熟練。  
> * **隨機應變**：每長休一次，在一次能力檢定擲出後、GM 宣布結果前，可額外擲 1d4 加在該次總值。  
> * **靈活輕甲／靴**：選擇取得一件皮甲，或一雙精良行旅靴；選靴時，每長休一次可重擲一次敏捷（身法）檢定並取較高結果。  
> * **江湖生存包**：取得旅行包、三日乾糧、麻繩 50 尺、火把 6 支與水囊。

### **無依孤兒**

固定：體質 +1；候選：力量 +2 或 敏捷 +2。可選利益：

> * **強健體魄**：氣血上限 +2。  
> * **野外生存**：取得生存熟練。  
> * **天賦直覺**：取得感應熟練。  
> * **生存工具包**：取得旅行包、三日乾糧、草藥包、麻繩 50 尺與火摺。  
> * **殘缺初級秘笈**：指定一門與背景合理相符的武學，取得一份解鎖上限5的殘缺秘笈；仍須依正式修習規則入門與成長。

### **朝廷屬下**

固定：力量 +1；候選：體質 +2 或 智力 +2。可選利益：

> * **武器精通**：額外熟練一種核心武器。  
> * **官府背景**：在自身官府體系正常管轄範圍內，可證明公職身份並要求普通公務協助、查閱非機密公文或取得合理會面；越權、違法或機密要求仍須另行處理。  
> * **鎮壓者**：對明知你官府身份、且確實受該官府權力約束的普通人作威嚇時有優勢。  
> * **官製武器**：取得一件價格不高於 18 兩的普通核心武器。  
> * **官製護甲**：取得一件厚布甲、皮甲或鎖子甲；若選鎖子甲，起始銀兩減少 10 兩，最低可降至 0。

### **富家子弟**

固定：智力 +1；候選：魅力 +2 或 直覺 +2。可選利益：

> * **財力支持**：起始銀兩額外 +30 兩。  
> * **商業頭腦**：對估價、議價、辨識交易陷阱與商業帳目的合理檢定有優勢。  
> * **上流人脈**：與地方士紳、富商、文人或有正式身份的上層人士接觸時，若你的家世可被核實，第一次相關社交檢定有優勢。  
> * **家傳精良器物**：選擇一件內容庫價格不高於 30 兩的普通武器、護具或工具，將其品質提升為「精良」。它不是內容庫所稱的劇情級「名器」，不會因此取得額外未定義能力。  
> * **推薦信**：指定一個與家族合理有往來的勢力或人物。第一次憑信求見時，只要對方仍承認寫信者身份，即可直接取得基本會面機會；是否合作仍依利益與局勢處理。

### **流浪武者**

固定：力量 +1；候選：體質 +2 或 敏捷 +2。可選利益：

> * **武學天賦**：每個修習段第一次需要進行武學學習／研究檢定時有優勢。  
> * **武道精進**：對因時間不足、帶傷強練、偷學或殘缺來源而進行的武學修習檢定 +1。  
> * **低調無名**：陌生人若只憑江湖傳聞辨認你，計算辨認難度時把你的有效名望視為低 2（最低 0）；已經實際見過你或掌握明確身份資料者不受影響。  
> * **精良武器**：取得一件你熟練的核心武器，品質為「精良」。  
> * **江湖生存包**：取得旅行包、三日乾糧、麻繩 50 尺、火把 6 支與水囊。

### **隱居奇人**

固定：魅力 +1；候選：智力 +2 或 直覺 +2。可選利益：

> * **奇門遁甲**：取得格物推理熟練。  
> * **深山隱居**：在一般荒野中，只要有基本時間與材料，你能找到或建立不暴露於明顯天候危害的普通營地，不需為「能否找到基本宿營處」擲骰。危險地形、追兵或極端天候仍可形成挑戰。  
> * **低調無名**：陌生人若只憑江湖傳聞辨認你，計算辨認難度時把你的有效名望視為低 2（最低 0）。  
> * **野外工具包**：取得草藥包、抓鉤繩、麻繩 50 尺、火摺與三日乾糧。  
> * **雜學典籍**：從儒學、道學、佛學、信仰、歷史政治、天文地理中選一項取得熟練，並取得一冊與之相符的普通典籍。

### **毒血之人**

固定：智力 +1；候選：敏捷 +2 或 體質 +2。可選利益：

> * **毒物精通**：取得醫毒藥理熟練；辨識正式內容庫毒物時，若有足夠樣本與時間，第一次相關檢定有優勢。  
> * **毒性抗體**：對毒素造成的體質豁免 +1。  
> * **出其不意**：每場戰鬥第一輪，你的第一次攻擊檢定 +1。  
> * **毒與解毒工具包**：取得草藥包、1 份麻骨散與 1 份清毒散。  
> * **淬毒武器**：取得一件價格不高於 12 兩、你熟練的普通武器，以及 1 份可用於該武器的麻骨散；毒物仍按正式條目與使用方式處理。

### **求道之士**

固定：智力 +1；候選：魅力 +2 或 體質 +2。可選利益：

> * **修心養性**：對恐懼與魅惑的豁免 +1。  
> * **悟道之術**：從道學、佛學、信仰中選一項取得熟練。  
> * **冥思修行**：每長休一次，在一次短休中消耗氣血骰恢復時，可重擲其中一顆氣血骰並取較高結果。  
> * **古經**：取得一冊與自身修行傳統相符的古經；每長休一次，研讀至少 10 分鐘後，可令下一次與該傳統直接相關的知識檢定取得優勢。  
> * **護符／法器**：取得一件非超自然的修行信物。每長休一次，因恐懼或魅惑作豁免失敗後可立即重擲一次並使用新結果；其作用來自訓練與心理錨定，不是真實神力。

### **江湖後裔**

固定：魅力 +1；候選：力量 +2 或 體質 +2。可選利益：

> * **武學基礎**：指定一門與家傳相符的武學。若已實際掌握它，第一次針對該武學的學習／研究檢定有優勢。  
> * **武學天賦**：每個修習段第一次需要進行武學學習／研究檢定時有優勢。  
> * **武器精通**：額外熟練一種核心武器。  
> * **傳承武器／護具**：取得一件價格不高於 20 兩的普通武器，或一件價格不高於 28 兩的普通護具；它同時是可辨認家世的傳承物，但沒有額外未定義機械能力。  
> * **推薦信**：指定一個與家族舊交合理相關的勢力或人物；第一次憑信求見時可直接取得基本會面機會。

### **風野之民**

固定：體質 +1；候選：力量 +2 或 直覺 +2。可選利益：

> * **騎術專精**：取得騎術熟練；若已熟練騎術，則改為騎術專精。  
> * **野外生存**：取得生存熟練。  
> * **風中靈敏**：因強風、沙塵、雨雪、泥地或其他自然地形而進行的騎術與行旅追逐檢定有優勢；若主要難點不是天候或地形則不適用。  
> * **良馬**：取得一匹內容庫【良馬】。騎乘戰鬥依 `遊玩規則/遊玩流程/戰鬥.md`。  
> * **野外工具包**：取得旅行包、三日乾糧、麻繩 50 尺、草藥包與火摺。

### **異域來客**

固定：魅力 +1；候選：智力 +2 或 敏捷 +2。可選利益：

> * **異國風情**：第一次與一名對你出身抱有真實好奇或善意的 NPC 交涉時，相關社交檢定有優勢；對敵意、偏見或只重利益者不會自動生效。  
> * **出其不意**：每場戰鬥第一輪，你的第一次攻擊檢定 +1。  
> * **多國語言**：除角色本來掌握的語言外，再流利掌握兩種與出身合理相符的語言；若劇本不追蹤語言，改為相關語言／文書辨識檢定有優勢。  
> * **異國武器**：選擇一種核心武器作為機械基準，取得其異域形制版本並熟練該武器；它不因此建立新的外功武器類別。  
> * **異國典籍**：從歷史政治、天文地理、醫毒藥理、信仰中選一項取得熟練，並取得一冊與故鄉相關的典籍。

### **凡俗之民**

固定：體質 +1；候選：力量 +2 或 智力 +2。可選利益：

> * **生活智慧**：從巧手、醫毒藥理、生存、洞察中選一項取得熟練。  
> * **低調無名**：陌生人若只憑江湖傳聞辨認你，計算辨認難度時把你的有效名望視為低 2（最低 0）。  
> * **商業頭腦**：對估價、議價、辨識交易陷阱與商業帳目的合理檢定有優勢。  
> * **實用工具／武器**：取得總價不高於 10 兩的普通工具與／或一件普通核心武器。  
> * **小額資金**：起始銀兩額外 +10 兩。
